  • Generative Control as Optimization: Time Unconditional Flow Matching for Adaptive and Robust Robotic Control

    Zunzhe Zhang*, Runhan Huang*, Yicheng Liu, Shaoting Zhu, Linzhan Mou, Hang Zhao
    NeurIPS 2026 (earlier version at ICLR 2026 Workshops LLA and ReALM-GEN)

    GeCO turns flow-matching robotic control into adaptive optimization, improving efficiency, robustness, and out-of-distribution awareness for VLA policies.

    arXiv PDF Project
    Abstract

    Generative Control as Optimization (GeCO) reframes flow-matching action generation for robotic control as adaptive iterative optimization. Instead of following a fixed integration schedule, GeCO learns a stationary velocity field in action-sequence space so inference can stop early for simple states and refine longer for difficult states. The same stationary geometry also provides a training-free signal for detecting out-of-distribution states, supporting safer deployment of Vision-Language-Action policies.

  • Virtual Community: An Open World for Humans, Robots, and Society

    Qinhong Zhou, Hongxin Zhang, Xiangye Lin, Zheyuan Zhang, Yutian Chen, Wenjun Liu, Zunzhe Zhang, Sunli Chen, Lixing Fang, Qiushi Lyu, Xinyu Sun, Jincheng Yang, Zeyuan Wang, Bao Chi Dang, Zhehuan Chen, Daksha Ladia, Quang Vinh Dang, Jiageng Liu, Chuang Gan
    ICLR 2026 International Conference on Learning Representations

    An open-world platform and benchmark suite for studying human-robot coexistence, embodied social intelligence, and multi-agent planning.

    arXiv PDF Project Code
    Abstract

    Virtual Community is an open-world platform for studying embodied social intelligence across humans, robots, and society. Built on real-world grounded 3D scenes and a multi-agent physics simulator, it supports social interaction, robot-human coexistence, and large-scale community generation. The paper introduces benchmark challenges for community planning and heterogeneous robot collaboration, highlighting open problems in high-level planning and low-level cooperative control.

  • Ella: Embodied Social Agents with Lifelong Memory

    Hongxin Zhang, Zheyuan Zhang, Zeyuan Wang, Zunzhe Zhang, Lixing Fang, Qinhong Zhou, Chuang Gan
    ICML 2025 MAS Workshop

    An embodied social agent with structured lifelong memory for open-world social interaction and multi-agent decision-making.

    arXiv PDF Project Code
    Abstract

    Ella is an embodied social agent designed for lifelong learning in a 3D open world. It combines foundation models with a structured, non-parametric long-term multimodal memory system, including name-centric semantic memory and spatiotemporal episodic memory. Through extended observation and social interaction, Ella retrieves relevant memories, plans daily behavior, builds relationships, and adapts in multi-agent community settings.
