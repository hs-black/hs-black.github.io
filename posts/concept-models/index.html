从 token 到概念：句向量生成与动态分段

交互2026-10-22

“明天上午十点，林医生会带三位同事来开会。”这句话包含时间、人物、数量和事件。模型可以逐个 token 预测它，也可以先生成一份句子表示，再把这份表示展开成文字。另一种选择是保留 token 输出，却让最昂贵的 Transformer 主干只处理几个压缩后的片段。三种路径改变了不同的东西：预测什么、保存什么，以及在哪个粒度上花计算量。

Meta 的 Large Concept Model（LCM）把一句话映射到 SONAR 向量，在句向量序列上生成下一个向量。Dynamic Large Concept Model（DLCM）让 token 表示形成可变长片段，在短序列上运行更大的主干，再返回 token 预测。“概念”在这两种模型里都有可执行的定义：前者是一份可解码的句向量，后者是一段 token 表示的汇总。理解它们，可以从一个小问题开始：下一句话有两种合理走向时，预测一个平均向量会发生什么？

1. 一句话怎样成为一个预测单位

把文档切成句子 \(s_1,\ldots,s_N\)，由固定的 SONAR encoder 得到句向量：

$$\htmlData{symbol=embedding}{z_i}=E(s_i)\in\mathbb R^{1024},\qquad p_\theta(z_{i+1}\mid z_1,\ldots,z_i).$$

这里 \(E\) 是句子编码器，\(z_i\) 是第 \(i\) 句的向量，\(N\) 是句子数。LCM 在这些向量构成的序列上工作。生成新向量 \(\hat z_{i+1}\) 后，SONAR decoder 根据它和目标语言逐 token 生成文字：

$$p_D(s\mid\hat z,\ell)=\prod_{t=1}^{|s|}p_D(w_t\mid w_{\lt t},\hat z,\ell).$$

\(w_t\) 是句子里的第 \(t\) 个输出 token，\(\ell\) 指定解码语言。于是一次完整生成包含两层自回归：外层依次生成句向量，内层将每个句向量展开成文字。文本输入、文本输出的语言覆盖取决于所用 SONAR encoder/decoder，生成主干本身处理相同维度的向量接口。

原始 LCM 的主干训练固定句子表示空间。输入向量先按每个坐标做 robust normalization，再投影到 Transformer 的隐藏宽度。设 normalizer 保存的第 \(j\) 个坐标中心为 \(\mu_j\)、尺度为 \(s_j\)，则 \(u_{i,j}=(z_{i,j}-\mu_j)/s_j\)，输出通过 \(z_{i,j}=s_j u_{i,j}+\mu_j\) 返回 SONAR 空间。Robust 中心取中位数，尺度依据配置中的分位数估计；官方默认的 gaussian_robust 还对尺度做高斯分布校准。统计量由训练数据的混合样本估计并保存，训练和生成加载同一份 normalizer，使两个方向的坐标变换对应。

这把许多底层工作移到了句子接口：句子如何切分、一个长句能压进多少信息、向量发生偏移后如何还原文字。原始实现提供 SaT 分句、SONAR 编码和预计算向量的数据流水线。预计算省下每次训练重复编码的工作，也增加数据存储：一亿个 1024 维 BF16 向量仅有效载荷就有 204.8 GB。原文、分句边界、向量和 normalizer 的版本需要能够对应起来，才能解释训练中的数据差异。

2. 预测均值与生成分布

最直接的 Base-LCM 用均方误差训练：给定前文 \(c=(z_1,\ldots,z_i)\)，预测下一句向量 \(a=f_\theta(c)\)，最小化 \(\mathbb E[\|Z-a\|_2^2\mid c]\)。把下一句向量的条件均值记为 \(\mu=\mathbb E[Z\mid c]\)，平方项可以展开为

$$\mathbb E[\|Z-a\|_2^2\mid c]=\mathbb E[\|Z-\mu\|_2^2\mid c]+\|a-\mu\|_2^2.$$

第一项由真实分布决定，第二项在 \(a=\mu\) 时最小。因此，理想 MSE 回归器输出条件均值。如果前文同时允许“同意方案”和“拒绝方案”，两种续写的向量可能形成两个区域；它们的平均位置与某一句可直接解码的续写之间，还隔着表示空间的几何和 decoder。

用一维例子算清楚：下一向量可能为 \(-2\) 或 \(+2\)，出现 \(+2\) 的概率为 \(\pi\)。条件均值是 \(4\pi-2\)，最小 MSE 是 \(16\pi(1-\pi)\)。当 \(\pi=1/2\)，预测 0 的 MSE 为 4；始终预测 +2 的 MSE 为 8。回归目标确实更喜欢中间位置，即使真实样本只出现在两端。

Diffusion LCM 学的是下一向量的条件分布。训练时，从真实下一向量 \(z\) 构造带噪版本 \(y_\tau=\alpha_\tau z+\sigma_\tau\varepsilon\)，其中 \(\varepsilon\sim\mathcal N(0,I)\)，\(\tau\) 表示噪声阶段；常用的方差保持形式满足 \(\alpha_\tau^2+\sigma_\tau^2=1\)。Denoiser 接收前文、带噪向量和噪声阶段，预测干净向量：

$$\mathcal L=\mathbb E\!\left[w(\tau)\left\|z-g_\theta(y_\tau,\tau,c)\right\|_2^2\right].$$

这个目标仍然使用平方误差，但现在预测的是 \(\mathbb E[Z\mid y_\tau,\tau,c]\)：不同的带噪观测具有不同后验。图中，\(\alpha=\sigma=\sqrt{0.5}\) 时，正端点的后验概率为

$$P(Z=2\mid y,c)=\operatorname{sigmoid}\!\left(\log\frac\pi{1-\pi}+\frac{4\alpha y}{\sigma^2}\right).$$

随着噪声降低，带噪状态可以逐渐区分两种续写。生成从随机噪声开始，多次调用 denoiser，通过所选采样器推进到干净向量；初始噪声与采样过程保留生成的多样性。一次去噪回归只是这条生成轨迹的一步。

Two-Tower LCM 把前文 contextualizer 与 denoiser 分开：前者对已有句向量做因果编码，后者在多个去噪步骤中反复 cross-attend 这份上下文。这样能够复用上下文表示。另一条路线用残差向量量化把句向量拆成多个码本索引，逐个预测索引并累加码向量。它重新获得离散采样接口，同时引入量化重建误差和多个码本步骤。连续生成与离散编码都要经过同一个最终检验：生成的表示能否展开成所需文字。

3. 句向量的误差，怎样落到数字和实体上

“三位同事”变成“四位同事”，整体语义仍很接近，任务却可能已经失败。LCM 的 SONAR fragility 分析发现，向量空间的小扰动可能使解码文本发生明显变化，数字条目、唯一标识、超链接和简短技术表达尤其值得检查。欧氏距离衡量向量变化；实体、数量与逻辑关系的保真需要落到解码文本上测量。

一个工程实验可以分三层做。先对原句编码并直接解码，记录表示瓶颈本身的重建误差。随后在归一化向量上加入不同强度噪声，再逆归一化、解码。最后换成 LCM 真正预测的向量，区分“表示可还原”“随机扰动下可还原”“模型生成后可还原”三种条件。

每层同时记录向量距离、外部语义相似度以及名字、数值、单位的 exact match；按句长和内容类型分桶。由此能判断误差来自句子切分、encoder 压缩、生成偏移，还是 decoder 对偏移敏感。原始工作还对 decoder 进行带噪向量训练，提高它面对不完美句向量时的恢复能力。

用一个分类边界可以看见机制。设某个简化 decoder 根据分数 \(a^{\mathsf T}z+b\) 的正负选择两个数字表述。向量扰动为 \(\Delta z\)，分数变化就是 \(a^{\mathsf T}\Delta z\)，其绝对值最多为 \(\|a\|_2\|\Delta z\|_2\)。如果原分数距离零只有很小的 margin，即使向量误差很小也能改变输出。实际文本 decoder 的边界更复杂，这个计算给出了可测量的方向：除误差大小，还要观察它沿敏感方向移动了多少。

4. 从固定句子到动态片段

一句话可能包含一个短回答，也可能包含很长的公式和条件。DLCM 把压缩粒度变成随输入变化的内部结构，同时保留 token 级交叉熵监督。因果 encoder 先产生 \(h_t=E(x_{\le t})\in\mathbb R^{d_{\rm tok}}\)。将相邻位置投影成扫描向量 \(q_{t-1}=W_qh_{t-1}\)、\(k_t=W_kh_t\)，用方向差异形成边界分数：

$$\htmlData{symbol=boundary}{p_t}=\frac{1-\cos(q_{t-1},k_t)}2,\qquad p_1=1.$$

两向量方向相同，分数接近 0；方向相反，分数接近 1。推理时以阈值决定 \(b_t=\mathbf1[p_t\ge0.5]\)，\(b_t=1\) 表示位置 \(t\) 开启新段。训练可对分数加温度后采样边界。原始设计把离散分段决策与语言建模损失解耦；encoder 表示继续通过可微路径学习，硬分段本身按明确规则产生。

设第 \(k\) 段的位置集合为 \(S_k\)，先做均值池化，再投影到概念主干宽度：

$$\htmlData{symbol=concept}{c_k}=W_{\rm up}\frac1{|S_k|}\sum_{t\in S_k}h_t,\qquad W_{\rm up}\in\mathbb R^{d_{\rm con}\times d_{\rm tok}}.$$

\(d_{\rm tok}\) 是 token 路径宽度，\(d_{\rm con}\) 是概念主干宽度。因果主干在 \(c_1,\ldots,c_M\) 上计算，token decoder 用自己的状态作为 query，读取概念侧的 key/value，最后预测下一 token。压缩发生在内部计算序列上，完整文本仍由逐 token 的概率模型生成。

如果共有 \(T\) 个 token、\(M\) 段，实际压缩比为 \(\htmlData{symbol=effective-ratio}{R_{\rm eff}}=T/M\)。在大 batch 上约束平均比率，可以让代码、数学表达和普通叙述采用不同段长。将平均边界概率记为 \(G\)，实际边界比例记为 \(F\)，目标压缩比记为 \(\htmlData{symbol=target-ratio}{R_*}\)，DLCM 使用的辅助项为

$$\mathcal L_{\rm aux}=\frac{R_*}{R_*-1}\bigl[(R_*-1)FG+(1-F)(1-G)\bigr]-1,\qquad R_*\gt1.$$

把离散统计 \(F\) 在当前求导中视为常量，有 \(\partial\mathcal L_{\rm aux}/\partial G=\frac{R_*}{R_*-1}(R_*F-1)\)。边界过多时梯度为正，梯度下降会降低边界概率；边界过少时方向相反。全局统计提供压缩预算，局部分数决定预算怎样分布。记录实际段长直方图和边界率，比只记录一个目标 \(R_*\) 更能说明模型在做什么。

5. 压缩后的信息，什么时候可以读取

池化把一整段信息放进一个向量，因此需要给它标明最早可用时间。若一段包含位置 1、2、3，只有读完这些位置后才能计算完整均值；若它的结束由位置 4 的新边界确认，就要等观察到位置 4 才能宣布旧段闭合。因果性要追踪向量实际依赖了哪些 token，以及分段决策何时可知。

为了把这个规则写成可执行的 mask，采用一个流式教学约定：新边界出现时闭合上一段，decoder 只读取已闭合段；文档结束标记闭合最后一段。把第 \(k\) 段的可用时间记作 \(a_k\)，在读到位置 \(t\)、预测 \(x_{t+1}\) 时使用

$$M_{t,k}=\begin{cases}0,&a_k\le t,\\-\infty,&a_k\gt t.\end{cases}$$

Decoder 还保留因果 token 路径，未闭合段中的已有信息可以沿这条路径继续影响预测。概念 smoothing 若混合相邻概念，也应将可用时间取所有依赖项的最晚时间。具体架构可以采用不同的移位、在线更新和缓存方式；每种方式都需要为池化、平滑和解码写出同样明确的依赖契约。

一个强回归测试是固定前缀 \(x_{\le t}\)，随机替换未来 token，再比较位置 \(t\) 的 logits。正确的因果实现应保持一致。这个测试同时穿过 encoder、边界判定、pooling、平滑、cross-attention 和缓存，能够发现单看一个三角 mask 时遗漏的依赖。训练时一次看到完整序列，尤其需要检查离线池化与流式解码是否实现相同的条件分布。

6. 复制 KV 怎样改变 softmax

DLCM 的实现讨论了一个典型硬件问题：token query 长度为 \(T\)，概念 K/V 长度为 \(M\)，不同 token 的概念可见范围随段长变化。规则布局更容易利用高效 attention kernel，因此可以用 repeat_interleave 把概念 K/V 展开到 token 长度。评价这种变换时，需要一起检查可见性和归一化权重。

先固定一个 query，假设它能读取两个概念，缩放后的分数为 \(s_1,s_2\)，value 为 \(v_1,v_2\)。每个概念出现一次时，权重为 \(e^{s_j}/\sum_k e^{s_k}\)。如果概念 \(j\) 有 \(m_j\) 个可见且完全相同的副本，合并这些副本后的权重变为

$$\tilde A_j=\frac{\htmlData{symbol=multiplicity}{m_j}e^{s_j}}{\sum_km_ke^{s_k}}=\operatorname{softmax}_j(s_j+\log m_j).$$

重复次数形成了一个 \(\log m_j\) 的加性偏置。若目标是保持“每个概念一个条目”的 attention，则给每个副本减去 \(\log m_j\)，合并后的权重就能恢复。这里的 \(m_j\) 是当前 query 的实际可见副本数；因果 mask 截断了一部分副本时，它可能随 query 改变。位置编码和额外 bias 也必须保持副本的分数一致，才能使用这个等式。

因此，一个可复现的布局优化应先明确目标函数：按唯一概念归一化，或按展开后的位置归一化。两种定义都能写成模型的一部分。工程验收则把 reference 与目标定义绑定，再比较不同段长、不同 query 位置、不同副本数下的输出与梯度。DLCM 公开描述给出了概念复制和 FlashAttention VarLen 的路径；完整移植还需要具体落实概念的移位、mask、位置和副本计权规则。上面的数值实验提供一项独立检查。

7. 把编码、主干和解码一起计费

序列缩短后，主干的两类成本以不同速度下降。设原长度为 \(T\)，实际压缩比为 \(R_{\rm eff}=T/M\)，概念数约为 \(T/R_{\rm eff}\)，概念主干宽度为 \(d_{\rm con}\)。同样层数和宽度下，稠密投影与 MLP 的算术量约按 \(Td_{\rm con}^2/R_{\rm eff}\) 变化，概念 self-attention 的 QK/AV 部分约按 \(T^2d_{\rm con}/R_{\rm eff}^2\) 变化。若同时增大 \(d_{\rm con}\)，节省的计算会被重新分配给容量。

$$C_{\rm DLCM}=C_{\rm enc}(T)+C_{\rm backbone}(T/R_{\rm eff})+C_{\rm dec}(T,T/R_{\rm eff}).$$

Encoder 和 token decoder 仍处理 \(T\) 个位置。唯一概念的 cross-attention 具有 \(T\times(T/R_{\rm eff})\) 的逻辑交互规模；展开 K/V 后，所用 kernel 的计算和存储账本应按实际布局重算。短序列主干带来的算术节省，与规则 kernel 带来的执行效率，是两项需要分别测量的收益。

用参数主导的粗略模型举例：token 侧有 \(P_t=1\)B 个稠密参数，概念主干有 \(P_c=3\)B，\(R_{\rm eff}=4\)。忽略 attention 的长度相关项和其他算子，每个原始 token 的乘加成本约为 \(2(P_t+P_c/R_{\rm eff})=3.5\) GFLOPs；同样 4B 参数全部逐 token 执行约为 8 GFLOPs。这个模型得到约 2.29 倍的算术比值，来自 token 侧仍需支付的固定部分。

LCM 还要加入句子 encoder、句向量生成和文本 decoder。若每个新句向量使用 \(K\) 次去噪，成本可按 \(C_{\rm SONAR\ enc}+C_{\rm context}+K C_{\rm denoise}+C_{\rm SONAR\ dec}\) 记账，各项再按实际输入、输出长度求和。平均句长、采样步数与输出语言都会影响总耗时；长句压缩更多内容，同时也增加表示保真的难度。

比较模型时，先在相同文本和质量指标下报告参数、激活参数、实际压缩比和总 FLOPs，再测相同设备上的吞吐与延迟。Token 侧和概念侧具有不同宽度，优化器缩放也需要按各自参数角色处理，见 μP 与超参数迁移。训练预算分配中的思想也适用：压缩比改变的是计算如何分配，最优配置要同时满足容量、数据与重建质量的约束。

8. 推导与工程练习

练习 1：均值为何优于任选一个答案

下一句的一维表示以 0.75 概率取 +2、0.25 概率取 −2。求最佳 MSE 预测与最小 MSE；再求始终预测 +2 的 MSE。带噪观测模型为 \(y=\alpha Z+\sigma\varepsilon\)，其中 \(\varepsilon\sim\mathcal N(0,1)\)、\(\alpha=\sigma=\sqrt{0.5}\)。观察到 \(y=0\) 后，后验均值是多少？

展开完整解答

条件均值为 \(0.75\times2+0.25\times(-2)=1\)。MSE 为 \(0.75(2-1)^2+0.25(-2-1)^2=3\)。始终预测 +2 时，MSE 为 \(0.75\times0+0.25\times16=4\)。当观测 \(y=0\) 时，两端点生成这个观测的似然相同，后验仍等于先验，因此后验均值仍为 1。改变带噪观测会改变后验，改变先验概率也会改变同一观测对应的去噪结果。

练习 2：段结束与可用时间

标量表示为 [2,4,6,8,10,12]，边界在位置 1、4、6 开启新段。采用“看到新边界才闭合上一段”的约定。预测位置 4 的 token 时，哪些完整概念可见？读到位置 6、预测下一 token 时呢？

展开完整解答

预测位置 4 的 token 时只读到了位置 3，尚未观察位置 4 的边界，因此第一个完整概念还没有进入可见集合，预测依赖因果 token 路径和更早的初始状态。读到位置 4 后，第一段 [1,2,3] 闭合，均值为 4。读到位置 6 后，第二段 [4,5] 也闭合，均值为 \((8+10)/2=9\)，可见概念值为 [4,9]。位置 6 本身开启新段，它的完整段表示要等待后续边界或结束标记。把未来位置的值改掉，当前这两份闭合概念应保持不变。

练习 3：推导副本补偿

两个概念的分数均为 0，value 分别为 1、7。第一概念有 2 个可见副本，第二概念有 4 个。求原始唯一概念 attention、展开 attention、按可见副本数补偿后的输出。

展开完整解答

唯一概念权重各为 1/2，输出为 4。展开后 6 份副本分数相同，每份权重 1/6；两组总权重为 1/3、2/3，输出为 \(1/3+14/3=5\)。给第一组每份减 \(\log2\)、第二组每份减 \(\log4\)，各组的未归一化质量分别为 \(2e^{-\log2}=1\)、\(4e^{-\log4}=1\)，恢复等权与输出 4。若因果 mask 只让第二组看到 1 份，它的补偿应改为 \(\log1=0\)，使可见副本的合计质量仍为 1。

练习 4：压缩预算往哪个方向调

目标压缩比 \(R_*=4\)，实际边界率 \(F=0.4\)。把 \(F\) 固定，求辅助项对平均概率 \(G\) 的导数，并解释梯度下降的方向。另设 token 侧 1B、概念侧 3B 参数，若实际压缩比只有 2，按稠密参数模型计算每个原始 token 的 FLOPs。

展开完整解答

导数为 \(\frac4{3}(4\times0.4-1)=0.8\)。当前边界率高于目标 0.25，降低 \(G\) 会降低辅助损失，方向是减少边界、增加平均段长。实际压缩比 \(R_{\rm eff}=2\) 时，稠密成本约为 \(2(1+3/2)=5\) GFLOPs/token，高于实际达到 \(R_{\rm eff}=4\) 时的 3.5 GFLOPs/token，增加约 42.9%。实验应同时报告真实压缩率和实算成本，才能解释训练中预算漂移；attention、pooling、布局展开和其他算子继续单独计入。

9. 运行 NumPy 实验

下载 lab.py，在有 NumPy 的 Python 环境中运行：

python lab.py

实验用有限支持分布验证条件均值和平方误差分解，独立按高斯似然核对去噪后验；再以可逐项检查的 token 状态验证闭合段的可用时间和未来扰动不变性。最后比较唯一概念与复制布局的输出、数值梯度和 mask 截断后的计数补偿，并检查辅助压缩项的梯度方向。

正常结果包含 all checks passed。把副本补偿中的“可见副本数”改成原始段长，保留截断 mask 再运行，观察输出差异；把在线读取改成直接读取当前整段的离线均值，再随机改写未来状态，观察因果测试怎样发现依赖。实验只使用构造的一维或小矩阵数据；SONAR 的真实实体保真需要额外加载 encoder/decoder，按正文的三层实验测量。
