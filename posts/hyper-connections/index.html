Hyper-Connections：从一条残差流到多路信息交换

交互2026-10-22

一个 Transformer 子层刚算出了新特征，接下来做什么？最熟悉的答案是加回输入：\(x_{l+1}=x_l+F_l(x_l)\)。几十层之后，词义、位置关系、推理中间结果都进入同一个向量。下一层能够读取这个总和，想单独保留某一部分信息，就需要用向量内部的通道来组织它。

Hyper-Connections 换了一种组织方式：每个 token 保留多条向量，子层选择从哪几条读取，再决定把结果写回哪里。宽度为 4096 的 MLP 仍然处理 4096 维输入，而残差状态可以同时容纳四条 4096 维向量。这里增加的是跨层保存和交换信息的空间。要判断这种改变是否值得，既要算清信息如何流动，也要算清多出的状态怎样进出显存。

1. 恒等通路留下了什么

先把一个 attention 或 MLP 记作一个子层，索引为 \(l\)。在 Pre-Norm 结构中，可以把归一化一起收进 \(F_l\)：例如 \(F_l(x)=\operatorname{MLP}_l(\operatorname{RMSNorm}(x))\)。相邻子层的状态满足

$$x_{l+1}=x_l+\htmlData{symbol=branch}{F_l}(x_l),\qquad x_l\in\mathbb R^d.$$

把等式逐层展开，从第 \(a\) 层到第 \(b\) 层有 \(x_b=x_a+\sum_{l=a}^{b-1}F_l(x_l)\)。旧状态前面的系数一直是 1。反向传播时，单层局部导数为 \(I+J_{F_l}\)，其中 \(J_{F_l}\) 是子层输出对输入的 Jacobian。恒等项给信号提供了一条直接通路，这也是深残差网络能够训练的重要结构条件。

直接相加还规定了一件事：所有历史输出以同一个累加状态进入下一层。Pre-Norm 的状态范数随深度增大时，一个新分支相对于已有状态的变化可能变小，相邻层表示会越来越相似；具体程度取决于分支尺度、相关性和训练过程。深层 Transformer 的稳定训练讨论了归一化、初始化和残差尺度。HC 进一步放开信息的存放位置，让不同历史贡献在多路状态中拥有不同的系数。

可以把它与 DenseNet 的思路连起来理解：保留历史能让后续层有更多选择。DenseNet 显式拼接许多层的输出；HC 用固定数量的流持续混合历史，深度增长时，每个 token 的状态大小始终是 \(nd\) 个元素。代价与表达能力都由这份固定大小的状态决定。

2. 读取、混合与写回

省略 batch 和 token 轴，令 \(\htmlData{symbol=state}{X_l}\in\mathbb R^{n\times d}\)：每行是一条残差流，每行有 \(d\) 个通道。一个子层包含三组连接：读取权重 \(p_l\in\mathbb R^n\)、写入权重 \(q_l\in\mathbb R^n\)、混合矩阵 \(C_l\in\mathbb R^{n\times n}\)。向量 \(p_l,q_l\) 都按列向量记。

$$z_l=\htmlData{symbol=pre}{p_l}^{\mathsf T}X_l\in\mathbb R^{1\times d},\qquad f_l=F_l(z_l)\in\mathbb R^{1\times d},$$ $$X_{l+1}=\htmlData{symbol=mix}{C_l}^{\mathsf T}X_l+\htmlData{symbol=post}{q_l}f_l.$$

读取是沿流轴求和，子层接收一个 \(d\) 维向量。混合保留并交换旧内容，写入把一个新结果按不同系数分发到各流。对新流 \(j\)，这条式子逐项写成

$$X_{l+1,j,:}=\sum_{i=1}^n C_{l,ij}X_{l,i,:}+q_{l,j}f_l.$$

因此 \(C_{ij}\) 的行 \(i\) 表示旧流，列 \(j\) 表示新流；计算使用 \(C^{\mathsf T}X\)。这与原始 HC 的残差矩阵方向一致。若实现把新流放在矩阵的行上，存储的矩阵就应取转置。形状相同的方阵尤其需要给轴命名。

完整张量通常为 [B, T, n, d]，\(B\) 是序列数、\(T\) 是本次处理的 token 数。Pre 得到 [B, T, d]，attention 仍在 token 轴上建立依赖，MLP 仍在通道轴上运算。一次 HC 只执行一次子层 \(F_l\)，多路状态共享这次结果。

3. 从普通残差开始学习

如果一开始每条流都等于输入 \(x\)，并设置 \(C_l=I\)、\(q_l=\mathbf1\)、\(p_l=e_{l\bmod n}\)，那么读取的是其中一条流，写入时每条流都加上同一份 \(F_l(x)\)。于是更新后各流都等于 \(x+F_l(x)\)。这里 \(e_k\) 是只有第 \(k\) 个位置为 1 的选择向量，流索引从 0 编号。逐层归纳就得到与同一组子层函数的普通残差路径相同的初始状态。

轮换选择读取的流，使各子层具有不同的读取位置。训练时，读写权重与混合系数可以逐渐分化，各流也随之存储不同内容。最终读出同样属于模型定义：原始 HC 对最后各流求和再做最终归一化；复用旧模型权重做等价性测试时，应把展开、读出缩放和归一化中的 epsilon 一并纳入测试。采用平均读出可直接核对上述复制状态的等价性。

静态 HC 为每个子层学习固定的 \(p,q,C\)。动态 HC 进一步让连接依赖当前 token 的内容。原始实现先对每条流的 \(d\) 个通道分别做 LayerNorm，得到 \(\bar X\)，再计算

$$[p\;C]=[p_0\;C_0]+s_\alpha\tanh(\bar XW_\alpha),\qquad q=q_0+s_\beta\tanh(\bar Xw_\beta).$$

这里 \([p\;C]\) 是把读取列向量接在混合矩阵左侧，形状为 \(n\times(n+1)\)；\(W_\alpha\in\mathbb R^{d\times(n+1)}\)，\(w_\beta\in\mathbb R^d\)。同一投影作用于每条流，但归一化后的输入内容不同，所以同一个 token 的各行系数也会不同。\(p_0,C_0,q_0\) 是可学习的静态部分，\(s_\alpha,s_\beta\) 是可学习尺度。

初始化时，动态投影权重为零，尺度为 0.01，静态部分采用前面的选择向量、恒等矩阵和全 1 写入。连接先从熟悉的残差行为出发，再学习内容相关的偏移。\(\tanh\) 限制的是动态项在给定尺度下的幅度；静态矩阵和尺度仍能在训练中变化。原始 HC 允许负系数，例如把某条流中的历史贡献减去，这提供了更自由的组合方式，也让长期相乘的尺度成为需要观察的对象。

4. 一层怎样选择过去的计算

设某个历史子层输出为 \(f_a\)，写入系数为 \(q_a\)。经过后续混合矩阵之后，它在第 \(b\) 层输入中的直接贡献系数为

$$w_{b,a}=p_b^{\mathsf T}C_{b-1}^{\mathsf T}\cdots C_{a+1}^{\mathsf T}q_a,\qquad b\ge a+1.$$

其中 \(p_b\) 是第 \(b\) 层的读取权重，中间乘积沿执行顺序传播旧状态；当两层相邻时，乘积为空，系数就是 \(p_{a+1}^{\mathsf T}q_a\)。这回答了一个具体问题：一份结果写入哪些流，沿途怎样交换，最后被读取了多少。对静态连接，它给出固定的历史混合权重；对动态连接，它描述一次前向过程中已经取定的权重，其导数还包含权重随输入变化的影响。

两路状态已经能演示串行与并行依赖的差别。保留第一路作为输入 \(h\)，让第二路累积输出。第一个子层只向第二路写入 \(F(h)\)，于是状态为 \([h,\;h+F(h)]\)。第二个子层用读取权重 \([1-\lambda,\lambda]\)，输入便是 \(h+\lambda F(h)\)。它的输出继续写向第二路，最终读到

$$h+F(h)+G\bigl(h+\lambda F(h)\bigr).$$

当 \(\lambda=0\)，两个子层都从 \(h\) 计算；当 \(\lambda=1\)，第二个子层依赖第一个的结果。中间值提供连续的依赖强度。这里的“并行”描述计算依赖；运行时是否真正并行，还取决于门控是否依赖前一步状态、执行图和调度器。

HC 用少量流为很多历史输出提供可学习的到达路径。另一条思路是保存深度上的候选输出，让当前子层直接给历史分配 attention 权重，见 Attention Residuals。前者递归维护固定宽度的状态，后者显式选择历史候选；比较它们时，需要同时看历史表示能力、存储量与跨设备读取成本。

5. 梯度沿哪些路径回来

先固定 \(p,q,C\)，并固定其他 token 的状态，考察当前 token 的局部导数。Attention 的完整 Jacobian 还包含 token 之间的交叉块。对子层输入施加一个小扰动 \(\Delta X\)。输出扰动由两条路径相加：

$$\Delta X_{l+1}=C_l^{\mathsf T}\Delta X_l+q_l\,D F_l[z_l]\bigl(p_l^{\mathsf T}\Delta X_l\bigr).$$

第一项沿多路残差直接传播；第二项先读取扰动，再经过子层导数，最后写回。\(DF[z](u)\) 表示子层在输入 \(z\) 处对扰动 \(u\) 的方向导数。若把每个通道的 \(n\) 条流依次堆成列向量，则整个局部 Jacobian 可以写成

$$J=I_d\otimes C_l^{\mathsf T}+\htmlData{symbol=jacobian}{J_{F_l}}\otimes(q_lp_l^{\mathsf T}).$$

\(\otimes\) 是 Kronecker 积：把前面矩阵的每个元素乘到后面整个小矩阵上。这个形状为 \(nd\times nd\) 的表达式说明，残差混合决定直接通路，\(q p^{\mathsf T}\) 决定子层导数怎样分配到各流。

若把子层暂时置零，堆叠后的映射是 \(C_{L-1}^{\mathsf T}\cdots C_0^{\mathsf T}X_0\)。每层取 \(C=1.02I\)，60 层后的放大倍数约为 \(1.02^{60}=3.281\)；取 \(C=0.98I\)，则约为 0.298。很小的单层偏差会积累成明显变化。训练中应观察若干深度区间的矩阵乘积、奇异值和状态 RMS，再结合梯度与 loss 定位来源。

动态连接还有门控变化带来的通路。写成方向微分，就能清楚看到全部项：

$$\begin{aligned}dX^+={}&C^{\mathsf T}dX+(dC)^{\mathsf T}X+(dq)F(z)\\&+q\,DF[z]\bigl(p^{\mathsf T}dX+(dp)^{\mathsf T}X\bigr).\end{aligned}$$

这里 \(dp,dq,dC\) 都由输入扰动经动态投影产生。对混合矩阵做约束，可以控制其中的直接通路；完整训练行为还取决于门控导数与子层分支。mHC 将这件事转化为明确的矩阵约束，并进一步处理多路状态的带宽成本。

6. 参数很少，为什么仍会变慢

原始动态 HC 的两个投影合计含 \(d(n+2)\) 个权重；混合和读写的计算量约按 \(n^2d\) 增长。对于 \(n=4,d=4096\)，它们远小于一个规模按 \(d^2\) 增长的稠密投影。GPU 上，耗时还取决于数据移动和 kernel 启动：每个 token 的残差状态从 \(d\) 增至 \(nd\)，反复读取、归一化、混合和写回这些元素，会消耗显存带宽。

取 BF16、\(B=2,T=4096,n=4,d=4096\)，一份四路状态有 \(BTnd=134,217,728\) 个元素，占 256 MiB；单路只需 64 MiB。一遍完整读取加写回便要移动 512 MiB。假定某次大批量 kernel 能达到 2 TB/s 的有效带宽，这次搬运的理想下界约为 0.268 ms。这个估算只用于识别量级；实际 kernel 还包含计算、同步以及其他张量访问。短 decode 的 token 数很少时，launch latency 又可能占主导。

一个可复现的诊断实验是固定 \(B,T,d\)，分别测“普通残差加法”“分开的 pre、mix、post 运算”“融合 mix 与 post 的实现”，同时记录 kernel 数、显存读写量和总耗时。然后分别增大 \(T\) 与 \(n\)：大 \(T\) 时看带宽利用率，小 \(T\) 时看启动间隙。mHC 的融合设计正是把矩阵混合、写回和相加合为一次状态访问；其实现细节在下一篇展开。

数值测试还应覆盖轴与布局。用非对称 \(C\) 和彼此不同的旧流，比较显式求和与矩阵实现；再做一次流的重编号：若置换矩阵为 \(P\)，同时变换 \(X'=PX,p'=Pp,q'=Pq,C'=PCP^{\mathsf T}\)，结果必须满足 \(X^{+\prime}=PX^+\)。这个不变量能检查流轴是否在 reshape、广播或矩阵乘法中混淆。把流轴合并进 batch 轴后，进入 attention 前仍须完成 pre 汇总，使 token 轴保持原本的语义。

训练比较需要两本账：固定 token 数与子层配置，观察额外状态带来的质量变化；固定训练时间或总预算，观察额外开销后的实际收益。同时记录最终读出、归一化、初始化和 checkpoint 策略，才能把连接形式的收益与其他训练改动分开解释。

7. 计算与设计练习

练习 1：手算一次读写

令 \(X=[2,6]^{\mathsf T},p=[1/4,3/4]^{\mathsf T},q=[1,1/2]^{\mathsf T}\)，\(C=\left[\begin{smallmatrix}0.75&0.25\\0.5&0.5\end{smallmatrix}\right]\)，\(F(z)=2z\)。求输出，以及误用 \(CX\) 得到的结果。

展开完整解答

读取为 \(z=0.25\times2+0.75\times6=5\)，分支输出为 10。按列混合得 \(C^{\mathsf T}X=[4.5,3.5]^{\mathsf T}\)，写入为 \([10,5]^{\mathsf T}\)，最终输出是 \([14.5,8.5]^{\mathsf T}\)。误用 \(CX\) 得到旧状态 \([3,4]^{\mathsf T}\)，最终为 \([13,9]^{\mathsf T}\)。非对称矩阵和不同旧值共同使方向差异可见。

练习 2：一份历史输出留下多少

某层用 \(q_a=[1,0]^{\mathsf T}\) 写入。接下来用 \(C=\left[\begin{smallmatrix}0.8&0.2\\0.2&0.8\end{smallmatrix}\right]\) 混合两次，再由 \(p_b=[0,1]^{\mathsf T}\) 读取。这份历史输出的直接贡献系数是多少？

展开完整解答

第一次传播到两路的系数为 \(C^{\mathsf T}q_a=[0.8,0.2]^{\mathsf T}\)，第二次变成 \([0.68,0.32]^{\mathsf T}\)，读取第二路得到 0.32。两条到达第二路的路径分别贡献 \(0.8\times0.2\) 和 \(0.2\times0.8\)，相加仍为 0.32。该值描述连接对历史输出的直接传递，后续子层也可能通过其非线性计算再次利用这份信息。

练习 3：初始化时每条流的梯度

取两路标量，\(C=I,q=[1,1]^{\mathsf T},p=[1,0]^{\mathsf T},F(z)=2z\)。求输出对两路输入的 Jacobian。若上游梯度为 \([1,1]^{\mathsf T}\)，输入梯度是什么？

展开完整解答

输出为 \(y_1=3x_1,y_2=x_2+2x_1\)，所以 \(J=\left[\begin{smallmatrix}3&0\\2&1\end{smallmatrix}\right]\)。输入梯度为 \(J^{\mathsf T}[1,1]^{\mathsf T}=[5,1]^{\mathsf T}\)。即使输入两条流数值相同，选择性读取也会让反向贡献不同。若两条流都从同一个 embedding \(h\) 复制，继续沿复制操作回传时还要求和，得到 \(dL/dh=6\)。

练习 4：比较一次训练的开销

前面 256 MiB 的四路状态跨 pipeline 边界发送，每个 micro-batch 经过该边界一次。链路有效带宽为 50 GB/s，单路基线为 64 MiB。估算额外传输时间，并设计检查是否被计算隐藏的实验。

展开完整解答

额外数据为 192 MiB，即 201,326,592 B。除以 \(50\times10^9\) B/s，得到约 4.03 ms 的传输服务时间。它是否增加迭代耗时取决于通信与计算的重叠。应固定 micro-batch 和 stage 划分，记录发送开始、接收完成、依赖该输入的计算开始三类时间，再比较 step time；并改变 micro-batch 数检查 pipeline 气泡。若通信仍在下一 stage 等待区间内完成，额外服务时间可能被隐藏；若接收决定计算的启动时刻，它就进入关键路径。该估算只覆盖这一条边界的前向消息。

8. 运行 NumPy 实验

下载 lab.py，在有 NumPy 的 Python 环境中运行：

python lab.py

实验使用 float64 检查四件事：复制流初始化与普通残差的多层等价性；非对称混合的显式求和与矩阵实现；流重编号等变性；静态与动态连接的方向导数。导数测试将解析结果与中心有限差分比较，动态测试包含归一化及 pre、post、res 三组门控的变化。

正常输出包含 all checks passed，导数相对误差应小于 \(10^{-6}\)。把动态导数里的 \((dC)^{\mathsf T}X\) 删除后重新运行，观察误差；再把动态尺度从 0.03 改大，研究遗漏项何时开始主导误差。这组 CPU 实验检验数值和结构，训练质量与 GPU 吞吐需要单独实验。
