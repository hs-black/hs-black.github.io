多个 checkpoint 怎样合成一个模型：从 Model Soups 到参数对齐

交互2026-10-22

同一个基座经过三次微调，分别擅长数学、代码和长文理解。把三个模型同时部署，权重显存和维护成本随之增加；只选一个，又可能放弃另外两个方向的收益。模型合并尝试在离线阶段组合这些 checkpoint 的参数，得到一个仍按原有架构运行的模型。

这件事的计算形式很简单：读取张量，做加减和加权，写回文件。真正决定效果的是三个问题：同一位置的参数是否有相同含义，多个训练方向如何相互作用，以及我们怎样衡量能力的取舍。Model Soups 从同任务的多次微调开始，Task Arithmetic 把学习结果写成向量，TIES 与 DARE 处理更新的冲突和冗余，Git Re-Basin 则进一步追问：两个网络的神经元，应该怎样一一对应？

从一个共同基座出发

把模型所有具名张量按固定顺序展平，记共同基座为 \(\htmlData{symbol=base}{\theta_0}\in\mathbb R^P\)，其中 \(P\) 是参数个数。第 \(i\) 个微调模型的参数是 \(\htmlData{symbol=model}{\theta_i}\)，它学到的更新可以写成任务向量：

\[\htmlData{symbol=delta}{\tau_i}=\theta_i-\theta_0.\]

“共同基座”具体到同一份权重版本、张量名称和结构。假设一个坐标在基座里是 2，数学微调后变为 2.3，代码微调后变为 1.9，那么两个任务在这个坐标上的更新分别是 +0.3 和 −0.1。这个差分把已经共享的预训练知识留在基座中，把后续训练的变化单独拿出来。

Task Arithmetic 使用一组系数 \(\htmlData{symbol=coefficient}{\lambda_i}\) 组合任务向量：

\[\theta_{\mathrm{merge}}=\theta_0+\sum_i\lambda_i\tau_i.\]

系数为正时沿任务更新前进，为负时沿相反方向移动。取两个系数都为 1，上面的坐标得到 \(2+0.3-0.1=2.2\)。系数控制的是更新幅度；它通常需要通过目标任务和保留能力的验证结果来选择。一个方向同时影响很多行为，因此还要测量数学、代码、通用语言建模等多个维度。

Model Soup 则直接对参数做加权平均。令 \(\alpha_i\ge0\)、\(\sum_i\alpha_i=1\)，便有：

\[\theta_{\mathrm{soup}}=\sum_i\alpha_i\theta_i=\theta_0+\sum_i\alpha_i\tau_i.\]

因此同一基座上的参数平均，也是受权重和为 1 约束的任务向量组合。两个模型各占一半时，上面的坐标得到 2.1；把两个任务向量各加一次则得到 2.2。区分这两种系数约定，能解释很多“同样是 merge，结果幅度却不同”的现象。

平均参数为什么可能有用

同一个任务用不同学习率、数据顺序或正则化训练，会得到略有差异的模型。若这些模型落在一个相连的低 loss 区域，平均参数可能消去一部分训练波动，同时保留共同的改善。Model Soups 的代表实验从共享预训练权重的多次微调出发，考察了视觉模型以及文本分类模型。

固定输入 \(x\)，在基座附近把模型的 logits 写成一阶展开。用 \(J_x\) 表示 logits 对参数的 Jacobian：

\[f_{\theta_0+\tau}(x)\approx f_{\theta_0}(x)+J_x\tau.\]

在线性近似有效的范围内，先平均参数、再计算 logits，与先计算各模型的 logits、再平均接近。这为参数平均提供了直观解释。实际网络的曲率会带来差异，因此可以沿着两端权重之间的直线，实测验证 loss：

\[\theta(t)=(1-t)\theta_A+t\theta_B,\quad 0\le t\le1,\] \[b(t)=L(\theta(t))-\big[(1-t)L(\theta_A)+tL(\theta_B)\big].\]

这里 \(L\) 是固定验证集上的平均 loss，\(b(t)\) 衡量中间点高出两端线性插值多少。正的峰值是 loss barrier。用 0、0.25、0.5、0.75、1 五个点初筛，能快速发现两个模型之间是否存在明显的高损失区间；再在值得尝试的区间细化搜索。

Uniform soup 给所有候选相同权重。Greedy soup 先按验证表现排序，从最好的一份开始，逐个尝试加入。如果当前已经接纳 \(m\) 份模型，新候选 \(\theta_i\) 对应的提议是 \((m\theta_{\mathrm{soup}}+\theta_i)/(m+1)\)；验证指标改善时才接纳。这里 \(m\) 统计已经接纳的模型数。被拒绝的候选会跳过，后面的候选仍然可以继续尝试。

这套选择需要一个固定的目标。若产品同时关心代码和长文，先约定指标权重或最低能力要求，再做候选搜索。持续查看测试集来调整权重，会把测试集逐渐变成调参数据。更可靠的流程是用验证集选择合并方案，锁定方案之后再报告独立测试结果。

同样的函数，也可能有不同坐标

考虑只有两个隐藏单元的 ReLU 网络。模型 A 的输入权重是 \([1,-1]\)，输出权重是 \([1,1]\)，于是：

\[f_A(x)=\operatorname{ReLU}(x)+\operatorname{ReLU}(-x)=|x|.\]

交换两个隐藏单元，模型 B 的输入权重变为 \([-1,1]\)，输出权重仍为 \([1,1]\)。它同样计算 \(|x|\)。直接平均 A、B 的权重，两个输入权重却都变为 0，输出也变为 0。两个端点都正确，中点丢掉了整个函数。

沿未对齐的参数直线，输入权重为 \([1-2t,-1+2t]\)，输出是 \(|1-2t|\,|x|\)。如果验证输入均匀分布在 \([-1,1]\)，预测目标为 \(|x|\)，那么平均平方误差为：

\[L(t)=\mathbb E_x\big[(|1-2t|-1)^2x^2\big]=\frac{(1-|1-2t|)^2}{3}.\]

这里 \(t\) 是模型 B 的混合比例。\(t=0.5\) 时，loss 达到 \(1/3\)。把 B 的隐藏单元先交换回来，整个插值路径的 loss 就都为 0。

一般的两层网络可写为 \(W_2\sigma(W_1x)\)。令 \(\htmlData{symbol=perm}{P}\) 为重新排列隐藏单元的置换矩阵，同时修改两侧权重：

\[W_1'=PW_1,\qquad W_2'=W_2P^\top.\]

逐元素激活满足 \(\sigma(Pz)=P\sigma(z)\)，所以新函数与原函数相同。若有隐藏层 bias，也要随 \(W_1\) 一起置换。Git Re-Basin 利用这种对称性，在等价的参数表示中寻找更匹配的一份，再进行插值或平均。

一种匹配方法是让两模型读取同一批校准输入，记录隐藏单元的激活矩阵 \(Z_A,Z_B\)，每行对应一个单元、每列对应一个样本。寻找 \(P\) 使 \(\|Z_A-PZ_B\|_F^2\) 最小，等价于最大化成对单元激活的内积之和，可以转成指派问题。这个目标提供了一种可测量的“单元含义相近”。

Transformer 的对齐还要遵守图结构：残差相加两侧使用相同的通道坐标，attention 中相关的投影、头划分和位置编码也有耦合约束。先列出允许的联合置换，再在这些约束内求匹配。原论文在 MLP、卷积网络和 ResNet 上研究了这种方法；把它扩展到独立训练的语言模型，需要继续验证可用对称性和跨模型激活的匹配质量。

TIES 怎样处理更新冲突

回到共享基座的微调模型。坐标已经对应之后，不同任务仍可能在同一参数上提出方向相反的更新。直接平均会抵消它们；大量很小的更新，也可能积累成噪声。TIES 将处理拆成三步：保留大的变化、选定每个坐标的方向、只平均同方向的更新。

第一步 Trim：对每个任务向量 \(\tau_i\)，按绝对值保留最大的 \(k\%\) 个坐标，其余设为零，得到 \(\htmlData{symbol=trim}{\widehat\tau_i}\)。这里的百分比针对每个任务的完整展平向量；实现若改成逐层阈值，便改变了各层得到的稀疏预算。

第二步 Elect sign：在第 \(j\) 个参数位置，把留下的更新相加，再取符号：

\[\htmlData{symbol=sign}{s_j}=\operatorname{sign}\left(\sum_i\widehat\tau_{i,j}\right).\]

因此方向由带符号幅度的总和决定。例如 +0.8、+0.7、−2.0 的和是 −0.5，最终选择负方向。较大的单次更新可以超过多个较小的相反更新。本文的图和实验统一约定：总和恰为零时，该坐标的合并更新取零。官方代码中的 resolve_zero_signs 默认尝试用所有坐标选定符号的全局多数方向补齐平票位置；复现实验时要一并记录这项约定。

第三步 Disjoint merge：令 \(\htmlData{symbol=selected}{\mathcal I_j}\) 收集方向与 \(s_j\) 一致、且值非零的任务，再在这些任务之间求平均：

\[\mathcal I_j=\{i:\operatorname{sign}(\widehat\tau_{i,j})=s_j,\ \widehat\tau_{i,j}\ne0\},\] \[\tau_{\mathrm{TIES},j}=\begin{cases}\dfrac{\sum_{i\in\mathcal I_j}\widehat\tau_{i,j}}{|\mathcal I_j|},&|\mathcal I_j|\gt0,\\0,&|\mathcal I_j|=0.\end{cases}\]

最后使用统一缩放系数 \(\lambda\)，得到 \(\theta_0+\lambda\tau_{\mathrm{TIES}}\)。下面每个任务只有四个参数，保留两个恰好对应 50%。第一列展示幅度如何决定符号，第二列展示分母为何等于参与平均的两个任务。

TIES 用方向一致性减少抵消，也改变了任务之间的权重。在例子第一列，任务 C 的 −2 完整留下，任务 A、B 的正更新被过滤。这个选择应由任务效果来评估：记录每层保留率、符号冲突率和更新范数，再看哪些能力随 \(k\)、\(\lambda\) 变化。若某层长期由同一个任务主导，可以检查该任务是否用了更大的学习率、更多步数，或不同的参数化。合并系数需要与训练形成的更新尺度一起解释。

DARE 保留期望，也引入方差

许多微调更新很小且存在冗余。DARE 随机丢弃一部分任务向量坐标，并放大保留下来的值，然后再使用相加、平均或 TIES 等方法合并。记保留概率为 \(\htmlData{symbol=retain}{q}\)，对应丢弃概率 \(1-q\)。对某个更新 \(\tau_j\)，独立采样 \(m_j\sim\operatorname{Bernoulli}(q)\)：

\[\htmlData{symbol=dropped}{\widetilde\tau_j}=\frac{m_j}{q}\tau_j.\]

它以概率 \(q\) 变成 \(\tau_j/q\)，以概率 \(1-q\) 变成零。于是：

\[\mathbb E[\widetilde\tau_j]=\tau_j,\qquad\operatorname{Var}(\widetilde\tau_j)=\frac{1-q}{q}\tau_j^2.\]

取 \(q=0.25\)、\(\tau_j=0.2\)，保留时更新为 0.8，平均仍为 0.2，方差却有 0.12。随着保留概率下降，单次采样的波动会增加。DARE 的缩放确保期望更新相同，实际选择仍需比较多个随机种子。

线性层的情况可以精确分析。固定输入 \(x\)，如果每个更新独立采样，某一输出的增量 \(\Delta y=\sum_j x_j\widetilde\tau_j\) 满足：

\[\mathbb E[\Delta y]=\sum_jx_j\tau_j,\qquad\operatorname{Var}(\Delta y)=\frac{1-q}{q}\sum_j(x_j\tau_j)^2.\]

若贡献分散在很多通道，波动有机会相互平均；若少数通道承载了主要贡献，随机丢掉其中一个就会显著改变输出。后续非线性和层间传播还会改变误差的影响，因此保留比例要结合实际激活、能力评测和重复种子选择。

DARE 与 TIES 的稀疏操作具有不同的选择规则：前者随机保留并做期望补偿，后者优先保留绝对值大的坐标，再按方向合并。把两者组合时，需要记录操作顺序、保留比例、随机种子和最终缩放系数；这些共同定义了一次可复现的合并。

把合并变成可验证的工程实验

形状相同，词表行的含义仍需核对

两个微调模型可能各自新增了特殊 token，并把不同 token 放进同一个 ID。例如 A 的第 32000 行表示 <sql>，B 的同一行表示 <code>。直接平均这一行，会混合两种符号的表示。PEFT 的模型合并文档专门提醒了新增特殊 token 的冲突；mergekit 提供按基座词表、并集词表等策略构建输出 tokenizer 的配置。

工程上先建立“token 内容 → 目标 ID”的映射，再对齐输入 embedding、输出语言模型头及相关 bias 的行。共享权重的模型还要保持输入、输出权重的绑定关系。只有一份模型拥有的 token，需要明确来源和初始化策略。词表统一后，再检查特殊 token ID、停止条件和 chat template，并用包含各自新增 token 的真实样例做编码、生成和解码检查。

这个问题可以缩小成两行矩阵：A 的词表是 [red, blue]、embedding 是单位矩阵；B 的词表是 [blue, red]、embedding 的两行也相应交换。两者都正确表示单词，直接平均第 0 行却得到 [0.5, 0.5]。按 token 内容重排后，red 的合并向量才保持 [1, 0]。词表、张量名和神经元置换，本质上都在回答同一个问题：相加的两个坐标分别指向什么？

差分精度、更新尺度和验证预算

任务向量常由两个接近的数相减得到。读取已有浮点权重后，用较高精度做减法与累加，最后再转换为部署 dtype，可以减少合并过程中新增的舍入误差。保存时记录基座的具体 revision、输入模型 revision、参数筛选规则、算法系数和 tokenizer 配置。大模型可以逐张量流式处理，峰值内存主要由同时驻留的输入张量、基座和累加缓冲决定。

第一次实验可以固定候选集合，比较最好单模型、uniform soup、少量权重的 task arithmetic，再加入 TIES 或 DARE。每增加一个方法，都沿用同一份验证集和相同的搜索预算。记录每个候选的数学、代码、长上下文和通用语言指标，保留完整的能力向量。平均分相近的两个模型，可能分别偏向不同产品需求。

诊断也可以按机制拆开：插值中段出现高 loss 时，检查坐标与基座版本；平均以后某一任务掉分时，检查更新范数和符号冲突；DARE 结果随种子剧烈变化时，减小丢弃率并定位激活集中通道；含特殊 token 的样例异常时，直接核对 tokenizer 与输出头的映射。每次只改变一个因素，比较固定样例和完整验证指标，才能让下一次合并有据可循。

当任务需要长期保持独立专长、并根据输入调用不同参数时，还可以把多个专家放进带路由的模型，参考 MoE Upcycling。参数平均产生一份共享权重，路由则保留多份专家并选择调用；两者对应不同的容量、通信和服务预算。

CPU 实验与练习

下载 NumPy 实验 lab.py

依赖可通过 python3 -m pip install numpy 安装，随后运行 python3 lab.py。实验先验证隐藏单元置换、TIES 数值、DARE 的均值与方差、词表重排，再训练五个小型线性回归模型，用独立验证集选 greedy soup，最后读取单独生成的测试集。所有样本由固定种子在本地生成。

默认运行中，greedy soup 选择第 3、0 号模型，验证 MSE 从最好单模型的 0.67141 降到 0.65554；独立测试 MSE 从 0.69170 降到 0.67191。把五个模型全部平均，测试 MSE 为 0.98095，因为其中一份候选的训练目标发生了系统偏移。这组 CPU 结果展示了候选筛选的作用，也方便检查“训练、选择、报告”三个数据集合是否分开。

接下来可以把回归训练中的目标偏移量从 1.5 改成 0，观察 uniform soup 与 greedy soup 的差距；再把 DARE 的通道数从 16 改成 64，检查方差是否缩小到四分之一。分别改变种子重复运行，记录验证集选中的候选、独立测试 MSE 和采样方差，便能区分一次幸运采样与稳定的趋势。

练习 1：平均参数和相加更新

基座 \(\theta_0=[1,2]\)，两个微调模型为 \(\theta_A=[1.4,1.8]\)、\(\theta_B=[0.9,2.5]\)。求权重为 0.25、0.75 的 soup，以及两个任务向量各取系数 1 的合并结果。

展开完整解答

两个任务向量为 \(\tau_A=[0.4,-0.2]\)、\(\tau_B=[-0.1,0.5]\)。Soup 直接计算 \(0.25\theta_A+0.75\theta_B=[1.025,2.325]\)。也可以先组合更新：\(0.25\tau_A+0.75\tau_B=[0.025,0.325]\)，再加基座。

Task Arithmetic 的两个系数都为 1，更新相加得到 \([0.3,0.3]\)，最终模型为 \([1.3,2.3]\)。直接把两份完整模型相加会得到 \([2.3,4.3]\)，其中共享基座出现了两次；用差分组合可以精确控制基座只出现一次。

练习 2：把 TIES 的每一步算清楚

三份更新为 \([0.8,-0.6,0.05,0.02]\)、\([0.7,0.9,-0.04,0.01]\)、\([-2,0.4,0.03,-0.06]\)。每份保留绝对值最大的两个坐标，基座为 \([3,2,1,-1]\)，最终缩放 \(\lambda=1\)。求合并权重。

展开完整解答

裁剪后的三行分别为 \([0.8,-0.6,0,0]\)、\([0.7,0.9,0,0]\)、\([-2,0.4,0,0]\)。逐列相加得到 \([-0.5,0.7,0,0]\)，选定符号为 \([-1,+1,0,0]\)。

第一列仅保留 −2，平均仍为 −2；第二列保留 0.9、0.4，平均为 \((0.9+0.4)/2=0.65\)。后两列没有非零参与项，输出为 0。最终任务向量是 \([-2,0.65,0,0]\)，加基座得到 \([1,2.65,1,-1]\)。第一列两个正值之和为 1.5，小于负值的幅度 2，所以方向为负；第二列的分母等于被接纳的两个非零更新数。

练习 3：DARE 的波动如何随宽度变化

保留概率 \(q=0.25\)。先计算单个更新 0.2 在 DARE 后的均值、方差。再把同样的总贡献 0.2 均分到 16 个独立通道，求合计贡献的标准差和全部被丢弃的概率；换成 64 个通道会怎样？

展开完整解答

单个更新以概率 0.25 取 0.8，以概率 0.75 取 0。因此均值是 \(0.25\times0.8=0.2\)，二阶矩是 \(0.25\times0.8^2=0.16\)，方差为 \(0.16-0.2^2=0.12\)。

把总贡献均分到 \(d\) 个通道，每个通道原贡献为 \(0.2/d\)。独立方差相加后，合计方差是 \(d\times3(0.2/d)^2=0.12/d\)。\(d=16\) 时方差为 0.0075、标准差约 0.08660；\(d=64\) 时方差为 0.001875、标准差约 0.04330。全部丢弃的概率分别为 \(0.75^{16}\approx1.0023\%\) 和 \(0.75^{64}\approx1.009\times10^{-8}\)。通道数增加四倍时，均分贡献模型的标准差减半。

练习 4：没有训练误差，为什么合并后会失败

A、B 都计算 \(|x|\)，但它们的两个隐藏单元顺序相反。取混合比例 \(t=0.25\)，求未对齐合并的函数与 \([-1,1]\) 均匀输入上的 MSE，再求交换 B 隐藏单元后的结果。

展开完整解答

未对齐的输入权重是 \([1-2t,-1+2t]=[0.5,-0.5]\)，输出权重仍为 \([1,1]\)，所以函数为 \(0.5|x|\)。预测误差为 \(-0.5|x|\)，平方误差为 \(0.25x^2\)。均匀分布下 \(\mathbb E[x^2]=\frac12\int_{-1}^{1}x^2\,\mathrm dx=1/3\)，得到 MSE \(1/12\approx0.08333\)。

交换 B 的隐藏单元，并同步交换输入矩阵的行与输出矩阵的列后，B 的参数坐标与 A 相同。任意混合比例都保持输入权重 \([1,-1]\)，函数恢复为 \(|x|\)，MSE 为 0。实验脚本用 2001 个等距点验证同一现象；离散网格的均值会随采样方式与连续积分存在小的数值差异。
