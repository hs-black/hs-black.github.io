LLM 101

一次只猜一个 token

大模型生成文本的全部流程，其实是一个很短的循环

按 → 或点击屏幕继续

第 1 步 · 切词

模型看到的不是字，是 token

The464 cat3797 sat3332 on319 the262

文本先被切成片段，每个片段对应词表里的一个编号。常见词通常是一个 token，生僻词会被拆成几块。

（编号仅为示意，不同模型的词表各不相同。）

第 2 步 · 打分

对下一个 token，给整个词表打分

「The cat sat on the ___」，下一个是什么？

mat
41%
floor
18%
bed
12%
roof
6%
…
23%

概率为示意。最后一行是词表里其余几万个 token 加起来的份额。

第 3 步 · 采样

从分布里抽一个

  • 贪心：永远选概率最高的，稳定但容易重复
  • temperature：先把分数除以 T 再算概率，T 大更随机，T 小更保守
  • top-p：只在累计概率达到 p 的头部 token 里抽，砍掉长尾

想亲手拖一拖 T：新博客，从零开始 里有交互演示。

第 4 步 · 再来一遍

把新 token 接到末尾，重复

这叫自回归：每一步的输出，都是下一步的输入。

整体
文本prompt
→
切词tokenizer
→
Transformer算出分数
→
采样选一个 token
↺

箭头绕回去，直到抽到「结束」token 或达到长度上限。
