从小模型调参到大模型：μP 与超参数迁移

交互2026-10-22

在宽度 256 的模型上，学习率 0.001 训得很稳；把隐藏维度拉到 2048，照搬同一套超参数，loss 却开始震荡。每层都按标准做了随机初始化，前向初始激活也完全正常，问题出在哪？

答案在线性层的求和里。初始化时权重和特征互相独立，项数再多，正负也会相互抵消；但一旦开始反向传播，权重更新会顺着输入特征的方向对齐，再做矩阵乘时，所有项就会同向累加。模型越宽，单步更新对隐藏特征的冲击就越大。想在小模型上调好超参数、直接搬到大模型上用，就必须把初始化、前向缩放和优化器学习率当成一整套规则，随宽度同步调整——这套规则叫做参数化（parameterization）。

1. 初始化稳定以后，特征怎样学习

先看线性层里的一个输出坐标：\(z_i=\sum_{j=1}^{n}W_{ij}h_j\)，其中 \(n\) 是输入宽度，\(h_j\) 是输入特征。初始化时权重 \(W_{ij}\) 零均值、彼此独立，也和输入无关。记输入的二阶矩为 \(q=\mathbb{E}[h_j^2]\)，输出方差就是

$$\operatorname{Var}(z_i)=\htmlData{symbol=width}{n}\operatorname{Var}(W_{ij})q.$$

把权重方差设成 \(1/n\)，输出方差就钉死在常数上——这正是前向信号初始化做的事。但训练第一步就会打破独立性：参数更新 \(\Delta W\) 本身就是由输入 \(h\) 算出来的，再看更新带来的输出变化 \(\Delta z_i=\sum_{j=1}^{n}\Delta W_{ij}h_j\)，求和项不再抵消。

拿单个样本算一下最清楚。记损失对 \(z_i\) 的导数为 \(\delta_i\)，梯度就是 \(g_{ij}=\delta_i h_j\)。在梯度远大于 \(\varepsilon\) 时，Adam 经过偏差修正的第一步更新近似为 \(\Delta W_{ij}=-\eta\operatorname{sign}(\delta_i h_j)\)。把它代回前向，注意到 \(\operatorname{sign}(\delta_i h_j)\,h_j=\operatorname{sign}(\delta_i)|h_j|\)，立刻得到

$$\Delta z_i=\sum_{j=1}^{n}\Delta W_{ij}h_j\approx-\htmlData{symbol=lr}{\eta}\sum_{j=1}^{n}\operatorname{sign}(\delta_i h_j)\,h_j=-\eta\operatorname{sign}(\delta_i)\sum_{j=1}^{n}|h_j|.$$

每个 \(|h_j|\) 都是常数量级，\(n\) 个正数硬加起来，\(\Delta z_i\) 直接随宽度 \(n\) 线性膨胀（而不是初始化时的 \(\sqrt{n}\)）。想把单步特征变化稳住，隐藏层的 Adam 学习率就得按 \(1/n\) 缩小。换成真实的 mini-batch 和多步动量，对齐程度会更复杂，但根子都在这里：初始化靠随机抵消，训练更新靠相关性同向累加，两者的宽度尺度本来就不同。

反过来，为了求稳把所有层的学习率都压得太小也不行。那样网络越宽、隐藏特征动得越少，最后退化成在初始化附近做线性拟合（即 kernel / NTK 极限）——理论好算，却丢掉了深度学习最核心的特征学习能力。μP（maximal update parameterization，最大更新参数化）找的正是两者之间的平衡点：固定深度、输入输出维度和训练步数，当宽度 \(n\) 不断增大时，前向激活既不爆炸也不消失，同时每层隐藏特征的更新量始终保持在 \(O(1)\) 量级。

2. 把 μP 写成能执行的缩放表

拿一个双隐藏层 MLP 把规则落到纸面上。固定输入维度 \(d_{\mathrm{in}}\) 和输出维度 \(d_{\mathrm{out}}\)，只拉宽隐藏宽度 \(n\)，\(\phi\) 是逐坐标激活函数（如 ReLU 或 tanh）：

$$h_1=\phi(W_1x),\qquad h_2=\phi(W_2h_1),\qquad f=W_3h_2.$$

三个权重矩阵的形状依次是 \(n\times d_{\mathrm{in}}\)、\(n\times n\) 和 \(d_{\mathrm{out}}\times n\)。取基准宽度 \(n_0\)，记宽度倍率为 \(\htmlData{symbol=ratio}{r}=n/n_0\)、基准学习率为 \(\eta\)。先按最直白的方式写——代码里直接存前向生效的权重，前向不额外乘系数。下表对比了标准参数化（SP，即按 fan-in 初始化、全网共享学习率）与 μP 的缩放规则（所有权重均零均值初始化，表里列的是方差）：

权重通常的 SP 初始化μP 初始化μP / SGD 学习率μP / Adam 学习率
输入 \(W_1\)\(1/d_{\mathrm{in}}\)\(1/d_{\mathrm{in}}\)\(\eta r\)\(\eta\)
隐藏 \(W_2\)\(1/n\)\(1/n\)\(\eta\)\(\eta/r\)
读出 \(W_3\)\(1/n\)\(1/(nr)\)\(\eta/r\)\(\eta/r\)

在基准宽度 \(r=1\) 处，μP 和 SP 完全重合；真正拉开差距的，是模型变宽以后每一列怎么跟着缩放（当然，每层前面仍可以乘可调的常数增益）。

这张表不用死记，顺着“读出层为什么要缩得更狠”推一遍就能自己默出来。训练开始后，读出权重 \(W_3\) 会和隐藏特征 \(h_2\) 对齐，\(f=W_3h_2\) 把 \(n\) 个坐标同向加在一起；要想输出 \(f\) 维持在 \(O(1)\) 而不是随宽度炸掉，\(W_3\) 的每个元素本身就必须压到 \(O(1/n)\)，对应方差就是 \(n_0/n^2 = 1/(nr)\)。

\(W_3\) 缩小到 \(O(1/n)\) 之后，反向传回隐藏层的单坐标梯度也跟着掉到 \(O(1/n)\)，SGD 和 Adam 的分歧正是从这里开始的：

  • SGD 直接拿梯度做更新：输入层 \(W_1\) 的输入维度 \(d_{\mathrm{in}}\) 不随宽度增长，前向求和没有 \(n\) 来帮忙放大，为了抵消 \(O(1/n)\) 的梯度，学习率必须按 \(r\) 放大成 \(\eta r\)（隐藏层 bias 同理）；方形隐藏层 \(W_2\) 既有 \(O(1/n)\) 的梯度，又有沿 \(n\) 维输入的同向累加，一缩一放正好抵消，学习率保持 \(\eta\)；读出层 \(W_3\) 的梯度本来就是 \(O(1)\)，沿 \(n\) 维累加会放大 \(n\) 倍，所以学习率得缩成 \(\eta/r\)。
  • Adam 用二阶矩把梯度幅值归一化掉了：每层单步更新的量级只取决于学习率本身，因此只需盯住输入轴有没有变宽——\(W_1\) 和 bias 的输入维度固定，学习率保持 \(\eta\)；\(W_2\) 和 \(W_3\) 都沿宽度 \(n\) 求和，学习率统一缩成 \(\eta/r\)。

如果遇到非方形的隐藏层、fan-in 和 fan-out 按不同比例增长，就不能直接套方形矩阵那一行，得按各自的输入输出维度重新算一遍。

顺带提一个初始化时的好现象：既然 \(W_3\) 的初始方差是 \(1/(nr)\)，在随机独立假设下，初始输出的方差是 \(n\cdot\frac{1}{nr}\cdot\mathbb{E}[h_{2,j}^2] \propto 1/r\)，也就是说初始 logit 的 RMS 会随宽度按 \(1/\sqrt{r}\) 变小，越宽越接近 0，等训练跑起来、权重和特征对齐后才回到 \(O(1)\)。后面做坐标检查时看到初始输出偏小，别当成 bug。

3. 同一个读出层的两套坐标

真写代码时，大家往往不直接存缩小后的有效权重 \(W\)，而是把 \(1/r\) 挪到前向里：内存里存 \(V=rW\)，前向算 \(f=(V/r)h\)。这样 \(V\) 的初始化方差恒定为 \(r^2\cdot\frac{1}{nr}=1/n_0\)，不随宽度变化，正好能和 embedding 层共享权重。microsoft/mup 里的 MuReadout 用的就是这套写法。

但优化器现在看到的参数是 \(V\) 而不是 \(W\)，学习率也必须跟着换坐标。记有效权重的梯度为 \(g_W=\partial\mathcal{L}/\partial W\)，按链式法则有 \(g_V=g_W/r\)。SGD 对 \(V\) 更新一步，再换算回有效权重：

$$\Delta W=\frac{\Delta V}{r}=-\frac{\eta_V}{r}g_V=-\frac{\eta_V}{r^2}g_W.$$

为了和直接更新 \(W\)（学习率 \(\eta/r\)）完全等价，\(V\) 的学习率必须设为 \(\eta_V=\eta r\)。换成 Adam（先忽略 \(\varepsilon\)），梯度整体除以 \(r\) 会被一阶矩和二阶矩的比值直接约掉，换回有效权重 \(\Delta W=\Delta V/r\) 已经自带了一个 \(1/r\)，所以 \(V\) 的学习率保持 \(\eta\) 即可。这也是为什么不同代码里读出层的学习率看起来互相打架——单看学习率指数没有意义，必须连着前向倍率一起看。

这里有个很容易踩的工程坑：初始化缩放只能做一次。从 checkpoint 恢复训练时，磁盘里的权重本来就处在目标宽度对应的尺度上，如果顺手再跑一遍初始化转换，等于凭空把参数改坏。官方实现为此提供了 set_base_shapes(..., rescale_params=False)，只把形状元信息补回来，不动权重数值。恢复后拿同一批固定输入对一下 logits 和第一步更新，确认和中断前分毫不差，就能把这类隐患彻底堵住。

4. Transformer 中哪些轴在变宽

从 MLP 换成 Transformer，第一步是把“怎么变宽”说清楚。Transformer 里有四个可以独立拉宽的轴：hidden size、MLP 中间维度、attention 头数和每头维度 \(d_h\)。你是固定头数、让 hidden size 和 \(d_h\) 一起涨，还是固定 \(d_h\)、靠增加头数来扩宽？两种走法对注意力点积的影响不一样，必须先定好模型族。

模型族定下来之后，每个权重张量的轴就分成了两类：词表大小这种不随宽度变化的固定轴，以及 hidden size 这种跟着扩大的增长轴（比如 embedding 是一固定一增长，隐藏投影矩阵两轴都在增长）。mup 库的做法很直接：同时传入基准模型 base 和稍微加宽的 delta，对比两者的张量形状就能自动认出哪些轴在增长、按多少倍缩放，再把对应倍率写进优化器的参数组。base 和 delta 都只用来读形状，不必真拿去跑计算。

from mup import MuReadout, MuAdam, set_base_shapes

# Model 的输出头使用 MuReadout；这里宽度改变，深度与词表固定。
base = Model(width=256)
delta = Model(width=512)
model = Model(width=2048)
set_base_shapes(model, base, delta=delta)
optimizer = MuAdam(model.parameters(), lr=1e-3)

这套 API 默认线性层权重按 PyTorch 常规的 (fan_out, fan_in) 排布。一旦你自己写了转置存储、合并 QKV，或者上了张量并行把矩阵切到多张卡上，局部张量的形状就不再直接对应原来的 fan-in 和 fan-out。稳妥的办法是拿未分片的单卡模型打出一份完整清单——逐个参数列出 base shape、增长轴、初始化 RMS 和实际学习率——再去一条条核对分片实现。

Attention 里还有一处和第 1 节一模一样的陷阱。标准写法把 \(q^\top k\) 除以 \(\sqrt{d_h}\)，稳住的只是初始化时随机向量的方差；训练起来后，\(q\) 和 \(k\) 沿相关性对齐，点积就会按 \(d_h\) 线性累积。如果扩宽时 \(d_h\) 跟着变大，μP 会把点积缩放改成 \(1/d_h\)：

$$\mathrm{score}=\frac{\htmlData{symbol=attention-gain}{c}}{\htmlData{symbol=head-dim}{d_h}}q^\top k.$$

常数 \(c\) 在基准模型上选定即可。比如取 \(c=8\)，当 \(d_h=64\) 时，\(8/64\) 正好等于标准的 \(1/\sqrt{64}\)；等 \(d_h\) 扩大到 256，μP 的倍率降到 \(1/32\)，比标准的 \(1/16\) 多压了一半。反过来，如果你固定 \(d_h\)、只加 head 数，这一项自然不用动。

最后，深度、上下文长度、全局 batch 和训练 token 数都会改写优化问题。做宽度迁移时，先把这些变量全部钉死，只让宽度动；至于加深网络带来的残差累积，属于另一条轴，可以对照深层 Transformer 的稳定训练单独看。

5. 从坐标检查到超参数迁移

正式烧卡做超参扫描前，最划算的排雷动作是跑一遍 coordinate check（坐标检查）：挑三四个宽度，在完全相同的一小批数据上只跑几步更新，盯住每层激活的均值绝对值或 RMS。比较时一定要看逐坐标统计量，别直接拿整个向量的范数比——维度一变长，向量范数天生会跟着涨，反而掩盖了真实尺度。

光看激活本身还不够。把某层在固定 probe 数据上第 \(t\) 步的特征记为 \(h_t\)，顺手再算一下相对初始化的变化量：

$$\operatorname{RMS}(h_t-h_0)=\sqrt{\frac{1}{M}\sum_{i=1}^{M}(h_{t,i}-h_{0,i})^2},$$

其中 \(M\) 是这个 probe 张量的元素总数。每个宽度各自减去自己的初始特征 \(h_0\)，曲线画出来一眼就能分清毛病：如果激活 RMS 看着挺稳，但 \(\operatorname{RMS}(h_t-h_0)\) 越宽越小，说明特征没在学、退化成了 kernel 极限；如果变化量越宽越大，则是某处缩放没压住。把 embedding、每个残差分支和最终 logits 分开画，哪一层写错了倍率，曲线马上露馅。

坐标检查过了，再画学习率曲线。在 256、512、1024 三个宽度上，把数据分布、token 预算、有效 batch、调度比例全固定，拿几个随机种子扫同一组基准学习率（模型内部各参数组的实际学习率已经按 μP 换算好了）。把验证 loss 对基准学习率的曲线叠在一起：模型变宽后整条曲线通常会往下掉，我们要盯住的是谷底的横坐标有没有对齐，最好再挑一个更宽的模型抽检一遍这个区间。

看曲线时别只盯着单个最低点，顺便扫一眼谷底有多平坦、不同种子之间抖得厉不厉害。如果最低点总贴着搜索区间的边界，说明范围给窄了，得往外扩；如果谷底明显随宽度漂移，十有八九是实现里有某层漏了缩放，先回头查代码，再怀疑有限宽度效应。

整个训练链路里，最容易偷偷把 μP 写废的地方是学习率调度器。MuAdam 好不容易给隐藏层配好了 \(\eta/r\) 的参数组，结果某段训练代码在每步随手一句 group['lr'] = current_lr，直接把所有参数组覆盖成同一个值，宽度缩放当场失效。稳妥的写法是提前存好每组各自的初始学习率，每步只乘时间倍率：

base_lrs = [group['lr'] for group in optimizer.param_groups]
for group, base_lr in zip(optimizer.param_groups, base_lrs):
    group['lr'] = base_lr * schedule_multiplier(step)

在 warmup 起点、峰值和衰减中段各打一次参数组的 LR 比值，就能确认缩放倍率全程都在。权重衰减也要留神：无论优化器用耦合 L2 还是 AdamW 的解耦更新，实际生效的都是 \(\eta\lambda\)，换了参数坐标之后要确认每层的实际衰减一致，具体更新细节可以看优化器的状态与计算。

6. Adam 的数值尺度也参与迁移

前面推 Adam 换坐标时，我们顺口加了个前提——“忽略 \(\varepsilon\)”。落到代码里，分母里的 \(\varepsilon\) 却没法随便忽略。记偏差修正后的一阶矩和二阶矩为 \(\hat m\)、\(\hat v\)，更新方向为 \(u=\hat m/(\sqrt{\hat v}+\varepsilon)\)。如果某套参数化把整段梯度历史统一乘以正数 \(c\)，一阶矩乘 \(c\)、二阶矩乘 \(c^2\)，代进去就会变成

$$u'=\frac{c\hat m}{c\sqrt{\hat v}+\htmlData{symbol=epsilon}{\varepsilon}}=\frac{\hat m}{\sqrt{\hat v}+\varepsilon/c}.$$

一旦 \(c\) 很小，固定不变的 \(\varepsilon\) 在分母里就被相对放大了 \(1/c\) 倍，直接把更新步幅压扁。想在纯梯度缩放下保持严格等价，\(\varepsilon\) 必须跟着梯度一起乘 \(c\)：比如第 3 节读出层换坐标后 \(g_V=g_W/r\)，配套的分母常数就得改成 \(\varepsilon_V=\varepsilon_W/r\)。理论上完全等价的两套写法，跑着跑着轨迹分叉，很多时候就卡在这个 \(\varepsilon\) 上。

代个数进去最直观：梯度 \(10^{-7}\)、\(\varepsilon=10^{-8}\) 时，首步实际步幅还是学习率的 0.909 倍；把梯度缩小 1000 倍而 \(\varepsilon\) 不动，这个比例直接掉到 0.00990——全链路用 FP64 算也一样，纯属公式本身的效果。想知道某层有没有被 \(\varepsilon\) 卡住，直接记下每层 \(\sqrt{\hat v}\) 的分位数，看看有多少坐标落进了 \(\varepsilon\) 附近。

上了低精度还有另一重隐患：平方梯度和二阶矩比梯度小得多，有限的表示范围很容易把它们直接下溢成 0。真遇到更新莫名变小，把 optimizer state 的 dtype、实际更新 kernel 和零值比例一查，就能分清是 \(\varepsilon\) 主导还是浮点下溢。主流训练因此都会把优化器状态留在高精度，只在前后向用低精度算，细节可以接着看混合精度的数值范围。

跨参数化实验（如 Everett 等人的对比）也印证了这一点：mean-field 这类梯度天然偏小的参数化对 \(\varepsilon\) 极其敏感，而 SP 和 μP 在他们考察的规模下受影响小得多。真要调 \(\varepsilon\)，得看各层实测的 \(\sqrt{\hat v}\) 分布，别图省事全局一刀切压成极小值——没了分母保护，梯度一抖就容易炸。

7. 三篇论文怎样连接起来

把前面几节的原理放回文献里，正好串起三篇关键工作。Tensor Programs IV 在无限宽极限下把理论根基打牢：一个初始化稳定的网络，训练之后究竟是在做特征学习，还是退化成初始化附近的 kernel 动力学？论文借此推导出 μP 这套保证隐藏特征保持 \(O(1)\) 更新的缩放规则。紧接着，Tensor Programs V 把理论落到工程上，提出 μTransfer：在便宜的小模型上搜好超参数，按宽度规则零样本搬到大模型。

后来 DeepMind 的 Scaling Exponents Across Parameterizations and Optimizers 把视野又拉宽了一层，把 SP、NTK、μP、mean-field 和多种优化器放在一起系统比较。它的结论非常务实：更新与特征的 alignment 会随层号、宽度和训练阶段变化，因此并不只有 μP 一条路——只要按对齐规律配好逐层学习率指数，SP 一样能做到超参数迁移，而且像 Adam 的 \(\varepsilon\) 这种数值细节同样会左右结果。

回到日常实验，边界其实很清楚：μTransfer 直接迁移的是同一模型族内和宽度绑定的超参数（基准学习率、初始化增益、输出倍率等）。换了优化器，缩放指数就得跟着重推；要是深度、batch size、数据分布或训练长度也一起变，就别指望宽度规则包打天下，得把那些变量单独拆出来做对照。

8. 计算、诊断与实验

练习 1：计算一套实际学习率

基准宽度 256，目标宽度 2048，\(\eta = 0.001\)。用直接存有效权重的 μP，求三层在 SGD 和 Adam 下的实际学习率，以及目标读出层的初始化标准差。

展开参考解答

宽度倍率 \(r = 2048/256 = 8\)。SGD 的输入、隐藏、读出学习率依次是 0.008、0.001、0.000125；Adam 依次是 0.001、0.000125、0.000125。有效读出层的初始化方差为 \(1/(2048 \times 8) = 1/16384\)，开方得标准差 \(1/128 = 0.0078125\)。两种优化器共用这套初始化，只是学习率缩放各自按规则来。

练习 2：恢复同一个有效更新

令 \(r = 4\)，\(\eta = 0.02\)，有效权重梯度 \(g_W=0.8\)。在 SGD 更新中，如果改为存储 \(V=4W\)，\(V\) 该用多大的学习率？算出一步更新后的 \(\Delta V\) 和 \(\Delta W\)。

展开参考解答

有效权重的学习率是 \(\eta/r = 0.005\)，目标更新为 \(-0.005 \times 0.8 = -0.004\)。换到存储坐标后，梯度变成 \(g_V=0.8/4=0.2\)，学习率相应放大到 \(\eta r = 0.08\)，于是 \(\Delta V = -0.016\)，除以 4 换回有效坐标正好还是 \(\Delta W = -0.004\)。如果忘了换坐标、直接把 0.005 套在 \(V\) 上，有效更新会凭空缩小 16 倍。

练习 3：诊断 Adam 更新突然变小

首步梯度从 \(10^{-7}\) 掉到 \(10^{-10}\)，\(\varepsilon\) 始终固定为 \(10^{-8}\)。分别算一下“实际步幅 / 学习率”；想在纯坐标缩放下保持等价，新 \(\varepsilon\) 应取多少？另外还要查哪些日志才能排除浮点下溢？

展开参考解答

两次的比值分别是 \(10/11 \approx 0.9091\) 和 \(1/101 \approx 0.009901\)。梯度缩小了 \(10^{-3}\) 倍，把 \(\varepsilon\) 也乘 \(10^{-3}\) 改成 \(10^{-11}\)，比值就回到 \(10/11\)。排查下溢时，记下梯度、平方梯度和二阶矩的零值比例与分位数，再拿高精度对照跑一小段：高精度里依然出现的衰减来自更新公式本身，低精度多出来的零值才说明踩到了下溢。

练习 4：选择下一次昂贵实验

三个宽度的坐标检查全部正常。学习率扫了 [0.0001, 0.0003, 0.001]，三个宽度的最低验证 loss 全落在 0.001 上。现在能直接给大模型定学习率吗？下一轮实验怎么安排？

展开参考解答

不能——现在只知道最优点在已测区间的右边界上，谷底还没出现。先在最便宜的小模型上往右补测 0.003 和 0.01，把 U 形曲线两侧都画出来（就算跑炸了，也把 loss 和更新尺度记下来）；接着用中间宽度复核这段区间，给候选点多加几个随机种子看方差；最后才在目标宽度上拿中心候选值和它的一个邻居做验证，全程固定数据和训练协议。

下载 lab.py，动手跑一个双隐藏层 tanh 回归模型（输入维度 4，基准宽度 16，隐藏宽度依次拉到 16、32、64、128）。脚本用固定的训练数据和 probe 数据，直接打出 loss 和 probe 特征变化的 RMS：

python3 -m pip install numpy
OPENBLAS_NUM_THREADS=1 python3 lab.py
OPENBLAS_NUM_THREADS=1 python3 lab.py --sweep

跑完后，前五项自检应该全部打印 PASS：中心差分核对手写反向传播、有效读出与存储读出在 SGD 和 Adam 下连续六步严格吻合、对齐输入的闭式更新和直接计算一致，以及 \(\varepsilon\) 随梯度缩放后精准复现原来的 Adam 更新。紧接着默认实验会训 5 步，把 SP 和 μP 的特征变化随宽度的趋势并排打出来。

加上 --sweep 后，脚本会在三个基准学习率和两个随机种子上各跑 50 步。这组数据里，μP 在四个宽度上挑出的最佳学习率清一色都是 0.003——刚好卡在搜索下边界。照着练习 4 的思路，下一步顺手把 0.001 补进候选列表，就能把整条谷底曲线看全。
