深层 Transformer 怎样稳定训练

交互2026-10-22

12 层的模型训得好好的，拉到 96 层，loss 跑着跑着突然飙升。把学习率压低，曲线确实平了，但收敛慢得让人难以接受。遇到这种 spike，最该先问的不是学习率要不要再砍一半，而是：失控最先发生在残差流、注意力分数，还是参数更新这一步？

这三个位置管的是完全不同的事。残差和归一化决定信号与梯度怎么跨过几十上百层，注意力决定分数差怎么被压成概率，优化器则把梯度换成真正落到权重上的步长。如果只盯着一个全局 gradient norm，等于把几条完全不同的故障链路揉成了一个数——炸了也看不出是谁先动的。

深度把局部导数连乘起来

对第 \(\ell\) 层，记输入为 \(x_\ell\in\mathbb R^d\)、输出为 \(x_{\ell+1}=F_\ell(x_\ell)\)，局部 Jacobian 就是 \(d\times d\) 矩阵 \(J_\ell=\partial x_{\ell+1}/\partial x_\ell\)（整段序列的 attention 只是把 \(T\) 个 token 拼成 \(Td\) 维向量，多了跨 token 的导数块，链式法则的形式不变）。梯度从顶层 \(g_L=\nabla_{x_L}\mathcal L\) 传到底层，就是一连串转置矩阵连乘：

\[g_0=\htmlData{symbol=jac}{J_0}^{\!\top}J_1^\top\cdots J_{L-1}^\top g_L,\qquad \|g_0\|_2\le\Big(\prod_{\ell=0}^{L-1}\|J_\ell\|_2\Big)\|g_L\|_2.\]

这里的谱范数 \(\|J_\ell\|_2\) 是 \(J_\ell\) 的最大奇异值，也就是这一层最多能把某个方向的梯度放大多少倍。当然，这个上界假设每层的最坏方向刚好对齐，实际传播还会受各层旋转方向的影响；但深度的指数效应不需要多复杂就能看出来——哪怕只是标量，每层导数多出 2%（1.02），连乘 100 层就放大到 7.24 倍；反过来每层是 0.98，100 层后就只剩 0.133。

残差连接把每层写成 \(x_\ell+f_\ell(x_\ell)\)，局部 Jacobian 随之变成 \(I+J_{f_\ell}\)。多出来的恒等项 \(I\) 给梯度修了一条直达底层的快车道，但它并不保证乘积自动有界——刚才那个 \(1.02^{100}=7.24\)，本质上就是每层多了一个 0.02 的残差分支。所以除了靠初始化把分支压在合理尺度，训练过程中也得管住分支的大小和方向。

Pre-LN 与 Post-LN：归一化放在了哪条路径上？

用 \(N\) 表示归一化，\(f\) 表示 attention 或 FFN 子层。Post-LN 在残差相加之后做归一化，Pre-LN 在进子层之前做归一化：

\[\begin{aligned} \text{Post-LN:}\quad y&=N(x+f(x)),&J&=J_N(I+J_f),\\ \text{Pre-LN:}\quad y&=x+f(N(x)),&J&=I+J_fJ_N. \end{aligned}\]

差别一眼就能看出来：Post-LN 把 \(J_N\) 乘在了最外面，连恒等路径都要过一遍归一化；Pre-LN 则把恒等项 \(I\) 留在外面，主干直通下一层（实际 Pre-LN 模型通常只在所有 block 结束后的最顶层补一个 final norm，只过一次，不会逐层连乘）。

为了看清 \(J_N\) 到底对梯度做了什么，拿最干净的 RMSNorm（先省掉可学习的缩放参数）来算一下。对向量 \(x\in\mathbb R^d\)，记 \(r=\sqrt{\|x\|_2^2/d+\varepsilon}\)，那么：

\[N(x)=\frac{x}{r},\qquad J_N=\frac{I}{r}-\frac{xx^\top}{dr^3}.\]

拆开看它的两个特征方向：垂直于 \(x\) 的方向按 \(1/r\) 缩放，沿着 \(x\) 的径向方向只剩 \(\varepsilon/r^3\)。这在几何上很直白——当 \(\varepsilon\) 很小时，把输入整体拉长或压短，归一化后的输出几乎不动，所以沿径向的导数接近 0（LayerNorm 多做一步去均值，还会把全体分量一起平移的方向也压成 0）。换句话说，归一化把前向 RMS 稳在 1 附近的同时，也在反向传播里不断砍掉径向分量，并按 \(1/r\) 缩放正交分量。在 Post-LN 里，这把剪刀每一层都会落到主干梯度上；在 Pre-LN 里，主干绕开了它，只有子层分支会经过 \(J_N\)。完整算子推导和低精度归约见RMSNorm 的计算与优化。

Xiong 等人在 On Layer Normalization in the Transformer Architecture 里正是顺着这条链路分析的：初始化时 Post-LN 顶层附近的梯度明显偏大，不加 warmup 很容易第一步就把参数冲歪；Pre-LN 把恒等通路留出来后，初始化阶段的梯度平稳得多，对 warmup 的依赖也跟着减轻——不过实际训练里优化器二阶矩的冷启动和早期大梯度波动依然存在，所以 Pre-LN 通常还是会留一段 warmup，只是没那么脆弱了。

深度增加时，分支和残差怎样共同缩放？

Pre-LN 虽然保住了底层梯度，却带来了另一个副作用：主干一路只加不归一化，残差流的幅值会越滚越大。把均方幅值记作 \(r(x)^2=\|x\|_2^2/d\)，每过一个残差块都有：

\[r(x+f)^2=r(x)^2+r(f)^2+\frac{2x^\top f}{d}.\]

最后一项 \(2x^\top f/d\) 刻画分支和主干的对齐程度。哪怕分支与主干完全不相关，方差也会随层数线性累积；如果两者经常同向，主干 RMS 会涨得更快。主干越来越粗、分支输出又被 Pre-LN 卡在常数尺度，越往深层走，新分支能撬动主干的比例就越小。所以诊断深层模型时，单看归一化后的激活稳不稳定没用，得把残差 RMS、分支 RMS 和两者的夹角一起盯住。

想要 Post-LN 的表达力，又不想在深层炸掉，DeepNet 给出的解法是 DeepNorm：保留 Post-LN 的位置，但把残差缩放和初始化绑在一起改：

\[x_{\ell+1}=\operatorname{LN}(\htmlData{symbol=alpha}{\alpha}\,x_\ell+f_\ell(x_\ell;\theta_\ell)).\]

对于含 \(L\) 个 block（每个含 self-attention 和 FFN 两个子层）的 encoder-only 或 decoder-only 模型，系数取：

\[\alpha=(2L)^{1/4},\qquad \htmlData{symbol=beta}{\beta}=(8L)^{-1/4}.\]

这里 \(\alpha\) 放大每个子层的残差支路，\(\beta\) 用来缩小 FFN 权重以及 attention 的 \(W_V, W_O\) 的初始尺度，而 \(W_Q, W_K\) 保留基础初始化。拿 64 层模型代入，\(\alpha\approx 3.364\)、\(\beta\approx 0.210\)。

为什么要挑这几个矩阵成对缩放？因为从输入到子层输出，attention 的数值流经 \(W_V\) 和 \(W_O\) 两次投影，FFN 同样经过一升一降两次投影（\(W_Q, W_K\) 只决定 softmax 权重，不直接放大数值幅值）。把每条路径上的两段投影都乘上 \(\beta\)，分支的初始尺度和单步更新扰动都会叠加压低，再配上放大 \(\alpha\) 倍的残差主干，一步参数更新就不会把几百层叠出来的输出掀翻。如果是带 cross-attention 的 encoder–decoder 架构，子层数变了，论文另外给了依赖 encoder/decoder 各自深度的系数公式——套用前先把每个 block 里的子层和投影路径数清楚。至于模型变宽（而不是变深）时怎么同步调初始化和学习率，那是μP 与超参数迁移要解决的问题。

注意力熵：分数尺度怎样改变信息流？

除了残差主干，注意力里还藏着另一条常见的失控链路：训练过程中 \(Q\)、\(K\) 的范数悄悄涨大，把注意力 logits 之间的差距越拉越开，softmax 迅速坍缩成几乎 one-hot 的尖峰。对单个 query，设 \(n\) 个可见 key 的基础分数为 \(z_i\)，用一个正数 \(a\) 整体缩放：

\[p_i(a)=\frac{e^{az_i}}{\sum_j e^{az_j}},\qquad \htmlData{symbol=entropy}{H(a)}=-\sum_{i=1}^{n}p_i(a)\log p_i(a).\]

记配分函数 \(Z(a)=\sum_i e^{az_i}\)，把 \(\log p_i=az_i-\log Z(a)\) 代回熵的定义，立刻写成 \(H(a)=\log Z(a)-a\,\mathbb E_p[z]\)。对 \(a\) 求导，利用 \(\frac{d}{da}\log Z=\mathbb E_p[z]\) 和 \(\frac{d}{da}\mathbb E_p[z]=\operatorname{Var}_p(z)\)，一阶项刚好抵消：

\[\boxed{\frac{dH}{da}=-a\operatorname{Var}_p(z)\le0}\qquad(a\ge0).\]

只要分数不完全相等，放大尺度 \(a\) 就一定单调压低熵（熵的单位是 nats，均匀分布时最大为 \(\log n\)，坍缩到单个位置时趋近于 0）。麻烦在于，softmax 的 Jacobian 是 \(\operatorname{diag}(p)-pp^\top\)——一旦 \(p\) 逼近 one-hot，这个矩阵几乎全零，梯度穿不过 softmax，对应的注意力头就像被锁死在当前位置上，很难再调回来。

回到缩放点积注意力，单头维度为 \(d_h\) 时，任意两个 key 的分数差满足：

\[\left|\frac{q^\top(k_i-k_j)}{\sqrt{d_h}}\right|\le\frac{\|q\|_2\,\|k_i-k_j\|_2}{\sqrt{d_h}}.\]

可见 softmax 有多尖锐，直接取决于 \(Q\)、\(K\) 的范数和夹角。当然，低熵本身不一定是坏事——负责复制或精确定位的头本来就很尖锐。真正危险的信号是熵坍缩（entropy collapse）：在固定验证样本和相同可见长度下，一批原本分散的头突然集体掉熵，同时伴随 QK 范数飙升、更新比例异常或 loss 抬升。Zhai 等人在 Stabilizing Transformer Training by Preventing Attention Entropy Collapse 里把这条因果链拆得很清楚，并顺势提出了用谱尺度卡住 logits 的做法。

从向量长度到矩阵谱尺度

最直接的拦截点就在注意力入口。Henry 等人的 QKNorm 沿每个头的向量维度做 L2 归一化，再乘一个可学习的标量尺度 \(s\)：

\[\widehat q=\frac{q}{\|q\|_2},\quad\widehat k_i=\frac{k_i}{\|k_i\|_2},\quad z_i=s\,\widehat q^\top\widehat k_i.\]

单位向量的点积落在 \([-1,1]\)，logits 的绝对值就被死死锁在 \(|s|\) 以内（实现时给分母加个小下限防除零，同时盯着 \(s\) 别一路涨飞）。这里有个工程上容易踩的坑：现在大模型里常用的 QK-Norm 往往用 RMSNorm 而不是 L2 归一化。忽略 \(\varepsilon\) 时，RMSNorm 输出的向量 \(L_2\) 范数是 \(\sqrt{d_h}\) 而不是 1，正好和常规注意力的 \(1/\sqrt{d_h}\) 配对；从一套实现搬配置到另一套时，千万别忘了把归一化口径和 attention scaling 一起换算。

如果说 QK-Norm 是守在注意力门口按住向量长度，σReparam 则是往上游退一步，把线性层权重矩阵的“方向”和“谱尺度”拆开：

\[\widehat W=\htmlData{symbol=gamma}{\gamma}\frac{W}{\sigma(W)},\qquad \sigma(W)=\|W\|_2.\]

只要谱范数 \(\sigma(W)\) 算得准，有效权重的谱范数就恒等于 \(|\gamma|\)：\(W\) 只管方向和内部结构，整体放缩交给单个可学习标量 \(\gamma\)。训练时不需要每步做完整 SVD，用上一轮的奇异向量热启动，跑一两步 power iteration（每次迭代主要是两次矩阵-向量乘）就能跟踪最大奇异值；推理时直接把 \(\widehat W\) 提前算好，零额外开销。

不过 power iteration 毕竟是近似跟踪：训练初期权重方向转得快时，步数太少容易低估真实谱范数，抽几层定期多跑几轮复核会更踏实，归约部分也要留够精度。对比来看，QK-Norm 改动极小、只拦注意力入口的 token 级尺度，现在大模型几乎默认标配；σReparam 把控制前移到线性层参数化本身，还能顺带约束谱尺度的增长速度，只是实现和训练开销略重一些。

把稳定性变成一组可以复现实验的量

光看一条全局 loss 和总 grad norm 根本没法排障。一套够用的最小监控面板，按“层 × attention head × 固定验证 batch”的粒度，把残差 RMS、分支 RMS、QK 范数分位数、注意力熵、梯度范数，以及参数的实际更新比例一起记下来：

\[\htmlData{symbol=update}{u_\ell}=\frac{\|\theta_\ell^{(t+1)}-\theta_\ell^{(t)}\|_2}{\|\theta_\ell^{(t)}\|_2+\epsilon_u}.\]

分子是经过优化器和 weight decay 后真正落到参数上的位移，\(\epsilon_u\) 只用来防除零。记这组指标时有三个细节容易漏掉：接近零初始化的参数组分母太小，得同时记绝对更新范数；多卡分片训练要先对各分片平方和做汇总再开方；跨上下文长度比较熵时，除以 \(\log n\)（\(n\) 为该 query 实际可见的 key 数，跳过 \(n=1\) 的首 token）才能归一化到同一刻度。

至于怎么拿注意力熵，千万别为了监控把每层 \(S\times S\) 的注意力矩阵全量物化出来——那样直接把 FlashAttention 省下的显存和吞吐全吐回去了。实际做法是主训练路径只打便宜的 QK 范数，每隔几百步拿一小批固定验证样本，只挑几层、少量 query（保持 mask、位置编码和 attention scaling 与主路径完全一致）重算一次完整分布就够了。

先出现的变化待验证的机制控制一个变量的探针
残差 RMS 随深度快速增长分支尺度或同向累积过大固定初始化与 batch，只改残差或分支缩放，对比层间 Jacobian 和分支比例
QK 范数上升，固定样本的熵骤降注意力 logits 分数差被放大只加 QK-Norm 或约束投影谱尺度，对比同一组头的分数与梯度
梯度范数平稳，实际更新突然变大优化器预条件、二阶矩状态或参数组尺度漂移加载完整 optimizer state，逐组核对更新量与二阶矩，回放同一批数据
特定长度或精度下首次出现非有限值归约、softmax 或 mask 边界的数值溢出同一张量跑一遍 FP32 参考路径，逐算子定位第一个分歧点

除了监控，还有两个工程环节最容易给人制造假象。第一个是梯度裁剪的顺序。全局范数裁剪把梯度缩成 \(g'=g\min(1,c/\|g\|_2)\)，但用 FP16 loss scaling 时，顺序必须是先累积完同一次更新的梯度，再 unscale，最后才裁剪（PyTorch AMP 文档专门强调过这一点）。举个直白的例子：真实梯度范数是 5、loss scale 是 128、阈值 \(c=1\)，正确顺序裁完范数正好是 1；反过来先裁放大后的梯度再除以 128，梯度直接被砍成 \(1/128\)，曲线看着稳了，其实模型几乎没在学。

第二个假象来自优化器本身：裁剪住了梯度，不代表裁剪住了参数位移。拿 Adam 第一步来算——省掉 \(\varepsilon\) 和 weight decay，偏差校正后 \(\widehat m=g\)、\(\widehat v=g^2\)，每个非零分量的更新都是 \(-\eta\operatorname{sign}(g)\)。全局范数裁剪对梯度做的是统一缩放，进到 Adam 里分子分母一除直接抵消，所以还得盯着上面那条实际更新比例 \(u_\ell\)。优化器的完整推导见优化器，warmup、batch 调度和 checkpoint 回放的实战细节可以看SmolLM3 训练过程。

排障时还有一条铁律：checkpoint 里一定要把权重、优化器状态、随机数状态和数据指针一起存下来，保证能从异常前几步原样重放。复现之后，先用单批数据切 FP32 排除纯数值溢出，再一次只动一个变量（学习率、归一化或分支系数）。别被一条更平的 loss 曲线骗了——调稳的代价如果是收敛变慢或吞吐掉一截，最终还是要在同等预算下拿验证 loss 说话。

残差连接还可以怎样设计？

前面讨论的 Pre-LN 和 DeepNorm，都是在单条残差流里调路径和尺度。如果把主干拓宽成多条并行的残差流，让网络自己学跨层怎么混合信息，就走到了 Hyper-Connections；但多路混合矩阵一样会跨层连乘，容易重新把梯度放飞，于是 mHC 用双随机约束把混合幅度锁住，Attention Residuals 则干脆让当前层用注意力沿深度挑历史表示。绕了一大圈，本质还是同一对矛盾：新算出来的信息怎么写进去，同时不把前面传过来的信息和梯度冲垮。

如果进一步让同一个残差块沿深度反复循环，参数梯度就会把多次展开的贡献叠在一起——训练展开、截断反传和停止策略见共享深度与递归计算；想直接量出每一层到底起了多大作用，可以接着看表示测量与删层干预。

用数字检查稳定性判断

练习一：归一化后的输出平稳，梯度会怎样？

给定 \(x=[3,4]\)，RMSNorm 的 \(\varepsilon=0\)、缩放参数为 1。求输出 RMS，以及平行、垂直于 \(x\) 两个方向上的 Jacobian 特征值。

推导与答案

\(r=\sqrt{25/2}\approx3.536\)，输出为 \([0.849,1.131]\)，RMS 恰为 1。沿 \(x\) 的特征值是 0，因为把输入整体放大不会改变输出方向和长度，径向导数自然为零；垂直于 \(x\) 的方向特征值为 \(1/r\approx0.283\)。多层串联时，下一层的线性变换还会把方向转开，所以不能只看单个特征值，得拿完整 Jacobian 算。

练习二：为什么要同时改 DeepNorm 的两个系数？

一个 decoder-only 模型有 64 个 block。计算 DeepNorm 的残差系数和初始化因子，并说明 attention 中哪些矩阵应用初始化缩放。

推导与答案

代入 \(L=64\)，得 \(\alpha=(128)^{1/4}\approx3.364\)，\(\beta=(512)^{-1/4}\approx0.210\)。需要乘 \(\beta\) 的是 attention 的 \(W_V, W_O\) 和 FFN 权重，\(W_Q, W_K\) 保留基础初始化。只拉大 \(\alpha\) 而不缩 \(\beta\)，分支的初始幅度和更新扰动并没有降下来；如果想亲手验证，从同一份随机权重出发，对比“只改 \(\alpha\)”“只改 \(\beta\)”“两者一起改”的输出变化量和层间梯度即可。

练习三：注意力熵为什么下降？

基础分数为 \([1,0,-1]\)，分别计算尺度 \(a=0\)、\(a=1\) 的熵，并求 \(a=1\) 处的熵导数。

推导与答案

\(a=0\) 时是均匀分布，\(H=\log3\approx1.099\)。\(a=1\) 时概率约为 \([0.66524,0.24473,0.09003]\)，算得 \(H\approx0.83240\)。此时分数均值 \(\mathbb E_p[z]\approx0.57521\)，二阶矩 \(\mathbb E_p[z^2]\approx0.75527\)，方差 \(\operatorname{Var}_p(z)\approx0.42440\)，因此 \(dH/da=-a\operatorname{Var}_p(z)\approx-0.42440\)。注意这个公式假设基础分数方向不变——真训练里方向也在动，排障时要把原始分数和 QK 范数分开看。

练习四：裁剪后为什么更新仍然很大？

Adam 首步遇到梯度 \([3,4]\)，先将其范数裁剪到 1。忽略 epsilon 与 weight decay，学习率为 0.01。求参数更新向量及其范数。

推导与答案

裁剪后的梯度是 \([0.6,0.8]\)。但 Adam 第一步做完偏差校正后，每个分量都会除以自己的绝对值，结果更新依然是 \([-0.01,-0.01]\)（范数约 0.01414）——跟完全不裁剪一模一样。后面几步虽有历史一、二阶矩的平滑缓冲，梯度裁剪和实际步长之间依然隔着一层预条件，不能混为一谈。
