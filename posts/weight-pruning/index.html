权重剪枝：从幅值到数据感知重建

交互2026-10-22

一个 4096×4096 的 BF16 权重矩阵占 32 MiB。把其中一半元素设成零，普通矩阵乘仍然读取完整的 32 MiB，也执行原来的乘法。剪枝因此有两个相连的问题：哪些连接可以删，以及删完以后用什么表示和算子执行。

第一个问题由模型和数据决定，第二个问题由稀疏模式、矩阵形状和硬件决定。把两者放在一起看，才能解释为什么某个方法保住了 perplexity，却没有降低 decode 延迟；也能理解为什么支持 GPU 加速的 2:4 模式，比任意删除一半权重更难优化。

1. 把剪枝写成输出重建

线性层的权重为 \(\htmlData{symbol=weight}{W}\in\mathbb R^{d_{\rm out}\times d_{\rm in}}\)，校准输入为 \(\htmlData{symbol=calibration}{X}\in\mathbb R^{d_{\rm in}\times N}\)，每列是一个样本。原输出是 \(WX\)。剪枝得到 \(\widehat W\)，希望在这些输入上保留原来的结果：

$$\min_{\widehat W}\frac1N\|(W-\widehat W)X\|_F^2,\qquad \operatorname{supp}(\widehat W)\in\mathcal M.$$

\(\|\cdot\|_F\) 是所有元素平方和的平方根，\(\mathcal M\) 是允许的非零位置集合族。非结构稀疏只规定总共保留多少元素；2:4 半结构稀疏则沿指定轴，把连续四个位置分成一组，每组最多保留两个非零值。固定稀疏率后，后者增加了局部位置约束。

这个目标把“重要权重”变成了“对当前输入分布有较大输出贡献的权重”。它也规定了校准数据的作用：输入的幅值、通道相关性，以及不同文本触发哪些特征，都会影响删除代价。一个权重很小，乘到经常很大的输入上，贡献仍然可能很大。

对单个输出通道，记原权重行为 \(w\)，修改量为 \(\Delta w=\widehat w-w\)。定义输入二阶矩矩阵 \(\htmlData{symbol=gram}{H}=XX^\top/N\)，则重建损失为

$$\mathcal E(\Delta w)=\Delta w\,H\,\Delta w^\top.$$

H 的对角项表示各输入通道的平均平方幅值，非对角项表示它们一起变化的程度。这里使用原始二阶矩；输入均值为零时，它也等于协方差。输出误差同时依赖权重改动和输入几何，这就是几类剪枝方法共用的起点。

2. 幅值与激活尺度

如果输入均值为零、通道彼此不相关、平均平方幅值相同，H 就与单位矩阵成比例。只删除第 j 个权重、保持其他权重不动，代价正比于 \(w_j^2\)。按绝对值从小到大删除，便得到幅值剪枝。

输入尺度不同的时候，这一步变成 \(\mathcal E_j=w_j^2H_{jj}\)。Wanda 用一个直接对应的分数：

$$s_{ij}=|W_{ij}|\;\|X_{j,:}\|_2.$$

其中 \(X_{j,:}\) 是校准样本里第 j 个输入通道的所有观测值。因为 \(\|X_{j,:}\|_2=\sqrt{NH_{jj}}\)，在同一层内按这个分数排序，与按单权重删除代价的平方根排序相同。Wanda 按输出行进行筛选；采用 N:M 模式时，再把候选限制到对应的小组内。

例如两个权重是 0.1 和 0.8，对应输入 RMS 为 10 和 1。只看权重，0.1 更容易被删；乘上输入尺度后，两者分数为 1 和 0.8，顺序反了。对于有少量高幅值通道的 LLM，这个差别会累积到许多层。

这幅图使用零均值、互不相关的输入，因此可以逐项相加删除代价。真实输入往往相关，删除多个位置时，损失还包含 \(\Delta w_j\Delta w_kH_{jk}\) 交叉项。单独对每个位置打分很便宜，而利用这些交叉项，可以进一步寻找替代被删连接的方式。

3. 相关输入怎样补偿被删权重

设某个输出为 \(y=x_1+x_2\)，两个输入均值为零、方差为 1，相关系数为 \(\htmlData{symbol=correlation}{\rho}\)。删除 \(x_1\) 的系数以后，可以把第二个系数从 1 改为 \(1+a\)。新旧输出之差是 \(-x_1+ax_2\)，平均平方误差为

$$\mathbb E[(-x_1+ax_2)^2]=1+a^2-2a\rho.$$

对 a 求导，最优值为 \(a=\rho\)，误差降为 \(1-\rho^2\)。当 \(\rho=0.8\)，保持其他权重不变的误差是 1；把第二个系数改成 1.8 后，误差变成 0.36。如果相关性为负，补偿方向也会反过来。

把这一推导推广到多维，就得到二阶补偿。假定 H 正定，要求第 j 个权重变为零，即 \(\Delta w_j=-w_j\)。对二次目标加上这个约束，拉格朗日方程给出

$$\Delta w^\top=-\frac{w_j}{[H^{-1}]_{jj}}H^{-1}e_j,\qquad \mathcal E_j^{\rm opt}=\frac{w_j^2}{[H^{-1}]_{jj}}.$$

\(e_j\) 是第 j 个位置为 1 的单位向量。H 的逆矩阵告诉我们，其他输入通道怎样共同补偿第 j 个通道；分母则决定这一删除动作的最小代价。这个目标使用 \(XX^\top/N\)，所以公式中没有额外的二分之一。

SparseGPT 将这类输出重建应用到大模型的逐层剪枝。它沿列处理权重，在固定部分剪枝决策以后，把误差传给尚未处理的权重，并利用共享的输入统计和分块更新降低成本。最终结果依赖处理次序、块大小和所选模式；固定掩码后的二次重建最优解，与同时寻找全局最佳掩码是两个不同层次的优化。

校准样本数较少、通道高度相关时，H 可能奇异或条件数很大。常见处理是加阻尼 \(H_\lambda=H+\lambda I\)，把求解限制在较稳定的方向。记录阻尼量、输入通道尺度和矩阵条件数，并在未参与校准的数据上验证重建误差，可以判断一次改善是否只是拟合了小样本中的相关性。相同的二阶思路也出现在GPTQ 量化中：一个把权重设成零，一个把它固定到低位网格上。

4. 从局部指标到可学习掩码

逐层重建优化的是当前层输出，最终任务优化的是整张网络的语言建模损失。MaskLLM 把每个 2:4 小组的六种合法掩码看作六个候选，为它们学习一个分布。原权重保持冻结，训练调整“选哪种连接”。

记六个二值掩码为 \(m_1,\ldots,m_6\)，学习到的 logits 为 \(\alpha_1,\ldots,\alpha_6\)。Gumbel-Softmax 用随机噪声和温度构造可微的混合系数 \(\pi_k\)，得到软掩码 \(\widetilde m=\sum_k\pi_km_k\)。损失的梯度可以经过混合系数传回 logits；导出时选取确定的候选掩码。

软掩码各元素可以是 0 到 1 之间的值，多个候选的并集可以覆盖整个小组。因此学习阶段和最终 2:4 执行阶段有不同的表示。应当同时检查训练中的软选择和导出后的离散模型，尤其在分布还没有集中到少数候选时。

一个小例子能看到这层差别：模型输出 \(x_1+x_2\)，当前样本为 [1,−1]。两个 1:2 掩码分别只保留第一个或第二个输入，输出为 1 和 −1；平均软掩码输出却为 0，与完整模型相同。软模型的误差可以小于每一个可部署的硬模型。降低温度、评估确定掩码以及检查任务损失，构成了学习掩码的实际训练闭环。

MaskLLM 还允许用幅值、Wanda 或 SparseGPT 给出的掩码初始化候选分布，再用数据学习更好的选择。这样可以把廉价的局部判断作为起点，把更昂贵的端到端优化用于改进。它消耗额外训练预算，比较时应同时列出校准 token、掩码学习 token 和最终质量。

5. 稀疏率怎样变成字节与时间

记非零密度为 \(\htmlData{symbol=density}{\rho}\)，权重有 P 个元素。若仍使用 dense 张量，存储成本保持 \(P b_v\)，其中 \(b_v\) 是每个值的字节数。CSR 按行保存非零值及其列编号，还需要每行的起止指针，近似成本为

$$M_{\rm CSR}\approx \rho P(b_v+b_i)+(d_{\rm out}+1)b_p.$$

\(b_i\) 是列编号字节数，\(b_p\) 是行指针字节数。BF16 值配 32 位列编号，每个非零需要 6 B；忽略行指针时，密度要低于 1/3，才能比每元素 2 B 的 dense 表示更小。50% 稀疏的 4096×4096 矩阵，CSR 约为 48 MiB，加上行指针后略多；dense 是 32 MiB。

2:4 用局部位置元数据避免逐元素保存大索引。以每四个 BF16 权重保存两个值、再保存 4 bit 位置元数据的布局计算，原来每组 8 B，现在为 4.5 B；上面的矩阵约为 18 MiB。具体实现还会有对齐和重排，最终应查看导出后的实际张量。

在支持相应稀疏指令的 GPU 上，2:4 kernel 可以沿规定位置跳过乘法。支持范围由 GPU 代际、数值格式、矩阵布局和库实现共同决定。NVIDIA Ampere 及之后的稀疏 Tensor Core 路径是常见例子；把权重设成零之后，还要转换为 kernel 接收的压缩格式。

推理时权重固定，压缩可以离线完成。训练时掩码可能每步变化，选择、压缩和转置表示都进入 step 时间，这部分留给稀疏预训练展开。对推理 kernel，则需要分别测小 batch decode 与大批量 prefill：前者往往更在意权重读取，后者更在意矩阵乘利用率。相同稀疏率在两种负载下可以得到不同收益。

6. 设计一次有解释力的压缩实验

可以先固定模型、校准 token 数和目标稀疏模式，比较幅值、Wanda 和 SparseGPT。第一层观察逐层输出误差，第二层观察未参与校准的验证 loss，第三层比较下游任务。最后用相同的压缩布局和 kernel 测量真实延迟。这样每一次比较都有相同的约束。

如果层重建很好、模型质量却下降，检查误差在哪些深度累积，以及校准集是否覆盖目标领域。可用代码、数学、多语言三类固定输入分别统计 H 的对角分位数、输出误差和最终 loss。模型中也有层间敏感度差异；同一全局稀疏率可以通过不同的逐层预算实现。

如果质量正常、吞吐不变，检查实际调度的是 dense GEMM 还是 sparse GEMM，再拆开格式转换、矩阵乘和后处理。用于测稳态 kernel 的压缩权重应提前准备好，同时单独记录部署加载时间。固定 M/N/K 和 dtype，测整段 decode 或 prefill，可以定位收益是否被其他层、通信或 KV 读取掩盖。

训练后静态剪枝、输入相关的激活稀疏和MoE 路由可以出现在同一个模型中。它们分别改变固定连接、当前 token 的中间向量和选中的专家。为每一层列出“哪些元素被省略、选择何时发生、哪个 kernel 实际利用它”，就能把这些优化放进同一份执行账本。

7. 计算与诊断练习

练习 1：幅值排序为什么会反转

两个独立输入的 RMS 为 8 和 1，权重分别为 0.1 和 0.6。只允许删除一个、其他权重不变，求两种删除的平均平方误差，以及 Wanda 的排序。

展开完整解答

删除第一个的误差为 0.1²×8²=0.64，删除第二个为 0.6²×1²=0.36。Wanda 分数为 0.8、0.6，所以保留第一个、删除第二个。幅值排序会删第一个。一次只删一个，输出改变量只有一项，因此该删除代价不依赖其他权重。

练习 2：用相关输入做补偿

输出为 \(x_1+x_2\)，两个输入均值为零、方差为 1、相关系数为 −0.6。删除第一个系数后，第二个系数应变为多少？最小误差是多少？

展开完整解答

修改量 a 的目标为 \(1+a^2+1.2a\)。令导数 \(2a+1.2=0\)，得到 a=−0.6，因此新系数为 0.4。最小误差为 \(1-(-0.6)^2=0.64\)，比保持系数为 1 时的误差 1 更小。负相关让补偿向减小第二个系数的方向进行。

练习 3：算一份真实稀疏存储

4096×4096 BF16 权重，密度 50%。CSR 使用 32 位列编号与行指针；2:4 使用每四个位置 4 bit 元数据。分别计算字节数。

展开完整解答

dense 为 \(4096^2\times2=33,554,432\) B，即 32 MiB。CSR 为 \(4096^2/2\times(2+4)+(4096+1)\times4=50,348,036\) B，约 48.016 MiB。2:4 为 \(4096^2/4\times4.5=18,874,368\) B，即 18 MiB。三项都应再按实际 kernel 的对齐及额外副本调整。

练习 4：软掩码通过了，导出为什么退化

样本 [1,−1]、权重 [1,1]，完整输出为 0。两个候选掩码是 [1,0] 和 [0,1]，训练用各 0.5 的软混合。求软模型和两个硬模型的平方误差，并设计验证步骤。

展开完整解答

软掩码为 [0.5,0.5]，输出 0，误差 0。两个硬模型输出分别为 1、−1，平方误差都为 1。应在训练检查点同时评估软模型、确定候选掩码和导出的压缩 kernel；先确认硬模型质量，再检查压缩输出与硬 dense-mask 参考一致。这三步分别检验松弛目标、离散化和执行格式。

8. 运行数值实验

下载 lab.py，在安装 NumPy 的环境中运行：

python3 lab.py

脚本用明确的校准矩阵检查 Wanda 的删除代价，枚举小矩阵的所有合法掩码；再把二阶删除公式与独立的受约束最小二乘比较，验证补偿结果和损失。最后检查稀疏格式的字节账本以及软、硬掩码的差异。

正常输出为各项 PASS。把输入相关系数从 0.8 改为 −0.8，预测补偿方向；再让两个输入几乎相同，观察 Gram 矩阵条件数。给 H 增加不同阻尼，并在另一组相关系数的输入上比较误差，可以得到一个很小但完整的校准分布迁移实验。
